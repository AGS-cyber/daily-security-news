Actively exploited

The day's lead is a reminder that "pre-auth in a web-exposed enterprise app" remains the most reliable path to a shell. Google is warning of renewed mass exploitation of CVE-2026-35273 in Oracle PeopleSoft, with attackers bypassing WAFs and dropping web shells, in activity the KEV entry ties to known ransomware campaign use and that reporting links to ShinyHunters-adjacent operators Attackers Bypass WAFs to Exploit Oracle PeopleSoft Flaw and Deploy Web Shells. The technical case for urgency is straightforward: a 9.8 CVSS, CWE-306 missing authentication for a critical function, reachable by an unauthenticated network attacker over HTTP against PeopleSoft Enterprise PeopleTools 8.61 and 8.62, with full confidentiality, integrity and availability impact. That it was first burned as a zero-day and is now being mass-exploited in a second wave tells you the patch curve never caught up. The WAF-bypass detail deserves emphasis: a signature-based edge control is not the compensating control here, and any team that deferred patching on that assumption should re-examine its exposure. CISA's required action for the KEV entry is to apply mitigations per vendor instructions and follow its risk-based update guidance — a federal requirement, not a universal deadline.

CISA also added a Microsoft SharePoint code injection flaw, CVE-2026-65660, to KEV on evidence of active exploitation SharePoint RCE and MikroTik RouterOS Flaws Actively Exploited in the Wild. At CVSS 8.8 (CWE-94), it is a different shape from the PeopleSoft bug: the vector requires an authorized — that is, authenticated — attacker, but grants network code execution, and the affected configurations span SharePoint Server subscription editions below 16.0.19725.20522 as well as the 2016 and 2019 releases. Its KEV ransomware-use field is unknown, so don't read absence of that tag as absence of criminal interest. The same KEV round added a MikroTik RouterOS flaw, which is worth noting for its reach rather than its metadata: on-prem collaboration servers and edge routers in one catalogue update is an unusually broad pair of surfaces to have to chase.

Breaches

The most instructive breach-adjacent item is not a new intrusion but a botched recovery. Two third-party GitHub Actions that had been compromised in a Mini Shai-Hulud campaign were re-enabled by their maintainer and stayed reachable for more than a week while still pointing at malicious code GitHub Actions re-enabled with Mini Shai-Hulud payload still active. No CVE applies; the failure is procedural. Remediation that reverts a workflow file without verifying the referenced action ref is intact leaves the supply-chain risk live, and publish-adjacent CI paths are exactly where minutes of exposure compound. If you pinned your workflows after that campaign, the follow-up question is whether the upstream repositories you depend on actually cleaned their tags.

Kiteworks has taken the rare step of telling customers to stop using its platform after what its CISO described as credible intelligence from federal authorities indicating a threat actor may attempt to target some customer systems Kiteworks urges customers to stop using platform after warning from federal intelligence agencies. Vendors patch; they rarely ask for shutdowns. There is no CVE or affected-version detail to work with here, so the operational read is contingency planning: know which internal flows terminate at that platform, have the outage conversation before it is forced, and preserve logs for whatever indicators arrive later.

Vulnerabilities

Elementor's Website Builder plugin carries a high-severity CSRF flaw that lets an unauthenticated attacker create rogue administrator accounts and take over a WordPress site, with a CVSS of 8.8 and — notably — no CVE identifier assigned yet Elementor CSRF Flaw Lets Attackers Take Over Sites After Admin Clicks Crafted Link. The exploitation condition is a privileged user clicking a crafted link, which is the classic reason CSRF flaws get underrated: the attacker supplies the request, the administrator supplies the session. The missing CVE is a practical problem beyond bookkeeping, since vulnerability-management tooling and scanner output keyed on identifiers will not surface this, and plugin fleets on managed WordPress estates are large. Track the affected version range from the vendor directly rather than waiting for a scanner to tell you.

Research

Two research pieces together describe where operator tooling is heading. Microsoft attributes a cluster of agentic-driven cloud attacks to Storm-3168, describing compromised service principals used for Azure reconnaissance, resource deletion and credential access, and linking the activity to JADEPUFFER Storm-3168: Agentic-driven cloud attacks using compromised service principals. Service principals are the canonical non-human identity problem: frequently over-permissioned, often outside the conditional-access and MFA policies written for humans, and attractive precisely because they blend into legitimate automation. The resource-deletion component matters as much as credential theft — this is availability risk, not just data risk.

Separately, a new Windows botnet tracked as x47.c uses xAI's Grok to select among predefined actions, maintaining persistence through an LLM in the loop, and drains AI API capacity as a monetization path New x47.c Windows Botnet Weaponizes xAI Grok, AI API Draining. The interesting part is not that a model is involved but what it replaces: hard-coded decision trees that defenders can fingerprint and that break when the environment changes. It also adds a second victim class — organisations whose AI spend, not just whose endpoints, is the thing being stolen.

Industry

A U.S. Army soldier was sentenced to 70 months in prison and ordered to pay nearly $300,000 in restitution for hacking AT&T and Verizon and stealing call and text metadata belonging to more than 100 million AT&T customers U.S. Soldier Gets 70 Months in Prison for AT&T, Verizon Extortions. Sentences like this are the visible end of telecom metadata cases, and the metadata itself is the point: it is not content, but it is enough to map relationships, movements and associations at population scale. For defenders in regulated sectors, the case is a useful benchmark for how seriously unauthorised access to subscriber records is treated — and a reminder that the lawful-access and insider routes into that data remain live.
