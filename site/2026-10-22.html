A honeypot caught a PHP2Shell exploit attempt before the flaws were public, CISA confirms four Plex flaws are being chained in live attacks, and GitLab reissues a CVSS 10.0 fix that the earlier update never covered. LiteLLM's release pipeline shipped a credential stealer, Railway warns of decrypted customer secrets, and INTERPOL tallies a large arrest round.

Actively exploited

Amazon's threat intelligence team detected an attempt to exploit the newly disclosed PHP2Shell vulnerabilities against its MadPot honeypot four days before those flaws were publicly disclosed, with the attempt originating from an IP address tied to a commercial anonymization network; the excerpt says the flaws have since come under broad exploitation in the wild following the release of patches Someone Tried to Exploit PHP2Shell 4 Days Before the Vulnerabilities Were Publicly Disclosed. Analysis: pre-disclosure probing followed by broad post-patch activity implies that slow remediation is exposure to live attacks rather than a comfortable advisory-reading window — but the supplied excerpt does not name the affected component versions, so exposure cannot be scoped from it.

CISA is warning that attackers are actively exploiting four vulnerabilities in Plex Media Server, chaining them in what is being called Plex2Shell CISA: Hackers chain Plex flaws in Plex2Shell attacks to breach servers. Internet-facing media servers are the target surface; the supplied excerpt does not describe the individual flaws or the chain's prerequisites.

Vulnerabilities

GitLab released fixes for a flaw that lets an attacker run code on a self-managed server without logging in, rated CVSS 10.0 and affecting every version going back to 7.0 — twelve years of releases Critical GitLab Flaw (CVSS 10.0) Could Allow Unauthenticated RCE Across 12 Years of Releases. The critical operational detail is that an earlier update covered only versions 19.2 and later, and the new fixed versions sit one patch above it, so administrators who already patched once have to patch again.

Node.js shipped security updates across all three supported release lines — 22.x, 24.x and 26.x — fixing ten flaws, the most serious being a bug in the bundled Brotli decompression code that the project says can allow remote code execution Node.js Brotli Decoder Bug Could Allow Remote Code Execution in All Supported Versions. Each line has a single fixed version; the excerpt does not supply the version numbers or the severity ratings of the other nine flaws, so treat the release as a whole rather than only the Brotli item.

Breaches

LiteLLM disclosed that attackers compromised "multiple independent security controls" to push a malicious version — 1.107.0 — of its Python package to both the Docker Hub registry and PyPI, containing a credential stealer and a backdoor LiteLLM Suspects GitHub Token Leak in AI Gateway Logs Behind Malicious Package Release. The suspected entry point is a leaked GitHub token found in AI gateway logs. Analysis: given that a stealer and a backdoor were both shipped through official distribution channels, anyone who pulled that version during the window should assume credential exposure in the environment that installed it; the excerpt does not say how long the window lasted or what else the token granted.

Railway says it found "anomalous activity" in systems storing customer environment variables, and that an unauthorized third party may have gained access to encrypted variables and, in some cases, obtained the decrypted contents Railway Says Intruder May Have Accessed Customer Secrets, Urges Credential Rotation. The company scopes the impact to a subset of users and is urging credential rotation — the practical read is that secrets held in those variables should be treated as exposed.

Research

Microsoft attributed the supply chain compromise of the ConnectWise Cloud Backup application to a China state-aligned actor it calls Storm-0940, which used ARTEX — a Go-based agentic AI penetration-testing framework that went closed-source after its abuse in attacks on South Korean financial institutions — to accelerate the operation China-Linked Hackers Use ARTEX AI Agents in ConnectWise Supply Chain Attack. Analysis: the reported use of an agentic framework to compress a supply-chain intrusion is the notable part, though the excerpt is truncated before quantifying how much time it saved.
