Eight selected stories and two distinct CVEs. Confirmed exploitation, compromised credentials and tampered update channels feature among the critical patches and new exploitation research.

Actively exploited

CISA Urges Patching Critical Vulnerability in BeyondTrust Remote Support CISA says CVE-2026-102764, a critical authentication bypass in BeyondTrust Remote Support, is being actively exploited to gain initial access and establish persistence. NVD’s affected configuration reaches Remote Support 26.2.3 and earlier; patches are available for supported versions 24.3.1 and later, so older deployments must upgrade first. NVD scores the flaw 9.3 under CVSS 4.0 with CWE-290, network attack vector, and no privileges or user interaction required. CISA’s required action points to BOD 26-04 and forensics triage requirements; that federal requirement is not a universal deadline.

Breaches

Hackers Use Compromised ConnectWise Credential to Sign In to 173 Microsoft 365 Tenants Unknown actors used a compromised ConnectWise Cloud Backup credential to sign in to 173 Microsoft 365 tenants, according to researchers tracking an active campaign. The backup service is built for managed service providers, so customer M365 environments are in scope. No CVE is attached in the supplied intelligence.

Attackers Tampered with AOMEI Backupper's Update Servers for Minutes to Deliver a Backdoor Attackers repeatedly altered the files AOMEI Backupper fetched from its own update servers, in windows of five to ten minutes at a time, so Windows systems checking for an update during one of those windows would download and run a backdoor. The source describes repeated tampering over a multi-month period, not a single poisoned release.

Vulnerabilities

Critical BlockStrap flaw lets hackers run code on Magento servers CVE-2026-103849 is a maximum-severity 10.0 flaw in Magento and Adobe Commerce: an improper neutralization issue in a template engine, CWE-1336, that could result in arbitrary code execution. NVD says exploitation does not require user interaction and that scope is changed. The supplied KEV check is a confirmed catalog miss, which does not prove exploitation has not occurred, and researchers warn attackers could soon exploit it.

Drupal patches critical RCE flaws, warns exploits may emerge soon Drupal patched two critical remote-code-execution flaws affecting any supported version of the CMS and warned that exploits may emerge soon. No CVE identifiers were supplied for the pair, so they cannot be matched to NVD or KEV records here.

Research

Targeted ads installed Candiru spyware in zero-click attacks Candiru spyware reached devices at Al Jazeera Media Network through targeted online advertisements in zero-click attacks that required only rendering the malicious ads, according to the supplied report. The excerpt does not supply the underlying vulnerability or full delivery chain.

MALFEX npm Package 'imgdecode' Hides Shellcode Loader in Windows Native Addon The malicious npm package imgdecode, tied to the MALFEX supply-chain campaign, hides a shellcode loader in a Windows native addon. It had been downloaded 979 times and remained available on npm at the time of the report.

Researchers Demonstrate OpenBSD Root Exploit Chaining 37-Year-Old Shared-Memory Bug Security firm Calif published a full local root exploit for OpenBSD 7.9 that chains a roughly 37-year-old integer overflow with a separate kernel flaw, bypassing KARL, SMAP and SMEP. The writeup and proof-of-concept code followed OpenBSD’s fixes.
