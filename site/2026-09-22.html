Actively exploited

The lead item is a switch. CISA added a stack-based buffer overflow in Zyxel's GS1900 series to KEV on evidence of active exploitation, and the detail is as unglamorous as it is actionable Zyxel and Veeam Flaws Under Active Exploitation With Command and SYSTEM Access. CVE-2026-7273 carries a CVSS 3.1 score of 8.8 and a CWE-121 classification; the description has a LAN-based, unauthenticated attacker sending a crafted HTTP request to the CGI program and potentially executing OS commands, with affected firmware on the GS1900-48HPv2 documented through 2.90(ABTQ.1)C0 and model-specific fixed builds above that. The vector is the part worth internalising: this is not an internet-exposed service. It is an attacker already on your network — a guest VLAN, an unpatched server, a compromised workstation — reaching management-plane hardware that almost nobody instruments. CISA's required action runs through BOD 26-04 with a due date only days after listing. The same report flags Veeam flaws under active exploitation for SYSTEM-level access, which is the more consequential half if you run the backup infrastructure that holds your recovery path.

Do not let the catalogue stand in for your risk register. Attackers are exploiting CVE-2026-93952 in on-prem VeloCloud Orchestrator New CVSS 10.0 VeloCloud Orchestrator Flaw Actively Exploited in Certificate-Based Setups, and the enrichment puts it at CVSS 4.0 9.5 — critical, unauthenticated, network-accessible, CWE-20 — yet the KEV lookup returns a confirmed miss. Only orchestrators configured to authenticate their Edges with certificates are affected in the described setup, and hosted versions including dedicated ones were already patched, which narrows the population considerably. But an on-prem orchestrator is the control point for an entire SD-WAN; successful exploitation compromises the confidentiality, integrity and availability of the orchestrator and the data it manages. KEV absence means no federal timeline and no automatic priority bump in a great many ticketing systems. If you are in that certificate-based configuration, you are the remediation deadline.

The two additions in CISA Adds Two Known Exploited Vulnerabilities to Catalog are a study in contrast. CVE-2026-76460 in Cisco Identity Services Engine is a CVSS 10.0 unauthenticated remote authentication bypass, arising from insufficient authentication control on an API endpoint (CWE-648) and letting an attacker through the web management interface on ISE 3.1.0 and 3.2.0 builds. ISE is a policy decision point for network access control; a bypass there is a key to the estate. Acronis Backup's CVE-2026-87886 is the quieter one: CVSS 7.8, CWE-276 incorrect default permissions producing local privilege escalation in the cPanel/WHM, Plesk and DirectAdmin backup plugins. Local privilege escalation matters exactly when you are already assuming a foothold — on shared hosting, the isolation boundary between tenants and a backup agent that can read everyone's files is the whole game. Both carry federal due dates that have already lapsed, which tells you the exploitation window opened before most people read the notice.

Then the ubiquitous one. CISA warns that three Linux kernel flaws are being exploited, one of them rated critical CISA alerts of active exploitation of three Linux kernel flaws. The kernel is the component you cannot meaningfully patch around, and the catalogue entries in that batch show why the effort is still worth it: CVE-2025-39964, a race condition (CWE-362) at CVSS 5.5, and CVE-2026-53266, an out-of-bounds write (CWE-787) at CVSS 8.8 in the netfilter bridge's ebtables SNAT ARP rewrite path. Both are marked known exploited, and both carried federal due dates that have already passed. A medium-severity kernel bug in use in the wild outranks a critical one that is not.

Vulnerabilities

WordPress fixed CVE-2026-93485, dubbed Comment2Shell WordPress Comment2Shell Flaw Can Turn Anonymous Comment XSS Into RCE via Admin Session, and the reason it deserves attention is the version range rather than the CVSS. The 7.1 score and CWE-79 label describe an unauthenticated stored XSS, but the affected span runs from 7.1 back through 4.7, and the write-up notes it reproduces on a default install: comment moderation is off by default and the previously-approved-commenter gate can be bypassed. The second stage is the interesting one — an anonymous comment plants a script that runs in an administrator's session and can reach server-side code execution. A confirmed KEV miss is not evidence nobody is using it, and a bug that turns an unauthenticated comment box into a path to the server will be sought out.

Industry

Microsoft's Digital Crimes Unit led a disruption of EvilTokens, a phishing-as-a-service platform whose operators compromised more than 12,000 Microsoft accounts across over 10,000 organisations EvilTokens PhaaS disrupted after compromising 12,000 Microsoft accounts. PhaaS takedowns are worth reading carefully: removing infrastructure is not the same as removing capability, and the affiliates who rented the kit are still in the business of stealing session tokens. The reason this category keeps working is that token theft does not look like a password attack — no failed logins, no spray, valid sessions from plausible geography. If your detection strategy is built around credential attacks, this is the gap.

Breaches

A joint advisory puts the North Korean Contagious Interview campaign at a minimum of 30,000 compromised devices across more than 100 countries, with funds and credentials taken from over 7,000 cryptocurrency wallets and $10.71 million stolen Contagious Interview Campaign Compromises 30,000 Devices, Steals $10.71M in Crypto. The target profile — individual web designers, engineers and cryptocurrency specialists — should be read as an acquisition strategy rather than a scattergun: those are the people whose laptops hold repository access, signing material and production credentials. Thirty thousand endpoints is not a campaign you can filter your way out of; it is a population of developer machines that has already been inside the perimeter.

Research

The most forward-looking item is CLOSEDQUORUM, described as the first reported autonomous AI command-and-control implant and surfaced through a research effort into AI-assisted intrusion The Closed Quorum: Inside the first reported autonomous AI C2 implant. Fully autonomous C2 means the implant no longer waits for an operator to make decisions; portions of the attack chain execute without human involvement. For defenders the practical shift is tempo: human-in-the-loop C2 imposes dwell time, jitter and conversation patterns that detection logic quietly depends on. Strip the operator out and what remains is behavioural — process lineage, beacon regularity, lateral movement that is faster and more consistent than a person would produce. Start calibrating for that now, because the tooling is already here.
