Vulnerabilities

CVE-2026-74580, dubbed Vghost, is a Linux vhost bug scored 8.8 High under CVSS 3.1 on a local vector (AV:L/AC:L/PR:L/UI:N) with changed scope AI-Found Linux Kernel Flaw Gives Local Users Root, and Can Break a Guest Out to the Host. Per the supplied description, the vring metadata cache that vhost treats as proof a region was already validated is not reset when VHOST_SET_VRING_ADDR replaces the descriptor, available and used rings, nor when VHOST_SET_VRING_NUM changes region sizes; with a device IOTLB attached, the stale cache keeps translating through a mapping that no longer covers the address. The reported result: local kernel memory read and write and root across nearly a decade of kernel versions, and in one virtualization configuration a guest writing into host memory and hijacking the program that runs the virtual machine. Tencent Zhuque Lab is credited with the find. The KEV check is a confirmed miss for this CVE, which does not establish that exploitation has not occurred.

CVE-2026-39919 in Ghostscript is the day's highest-scoring item: a heap-based buffer overflow rated 9.3 Critical under CVSS 4.0 (CWE-122) in the JPEG 2000 output adapter, affecting Ghostscript before 10.08.0 Ghostscript flaw lets hackers hijack servers via PDF uploads. A crafted PDF with mismatched component subsampling factors drives the non-samescale sub-byte-depth output path to allocate a row buffer sized for packed output while writing a full byte per column, corrupting chunk-allocator metadata to reach code execution. The supplied vector records network reachability, no privileges and no user interaction; delivery still depends on a crafted document reaching a Ghostscript-based pipeline, a condition the vector does not capture. Here too the KEV check is a confirmed miss, not proof that exploitation has not occurred.
