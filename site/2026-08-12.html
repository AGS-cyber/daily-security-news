Actively exploited

Microsoft's latest security release is the largest in the company's history, and one bug should outrank every other patch queued this week. Microsoft Patches 398 Flaws Including a Windows Driver Zero-Day Under Active Attack CVE-2026-68820 is a use-after-free in the Windows Ancillary Function Driver for WinSock, the kernel component that handles network socket operations. It requires an attacker to already have code execution on a machine, but from that position it grants SYSTEM privileges, turning any foothold into full control. The CVSS score is a comparatively modest 7.0, but confirmed in-the-wild exploitation makes that number almost irrelevant. CISA has added the flaw to its Known Exploited Vulnerabilities catalog, reinforcing the urgency of applying the Windows update before anything else.

Network devices are equally at risk. Cisco ASA and FTD Flaw Exploited in the Wild Can Trigger Remote DoS CVE-2026-20349 is a high-severity flaw in Cisco Secure Firewall ASA and FTD software, specifically in the Remote Access SSL VPN service. Insufficient error checking on HTTP requests lets an unauthenticated remote attacker force a device reload with one crafted request. Knocking a firewall offline is often as useful to an attacker as bypassing it, which is why CISA's active-exploitation warning deserves immediate attention. The CVSS 8.6 rating arguably understates the operational pain of a security appliance that keeps dropping off the network.

VMware vCenter is another active target. Attackers Exploit VMware vCenter Vulnerability to Gain Persistent Remote Access CVE-2026-59310 is a directory traversal in the vCenter Syslog server, rated critical at 9.8. Per QUIRSO, attackers are already exploiting it to gain persistent remote access to virtual infrastructure. Patches shipped recently, but the window between disclosure and offensive use has effectively closed. vCenter manages every workload and credential in the environment, so this should be treated as an emergency even though CISA does not yet list it as known exploited.

Finally, Hackers leverage new Microsoft SharePoint exploit in attacks a proof-of-concept for a critical Microsoft SharePoint RCE published by Rapid7 is already being used in attacks. Public PoCs collapse the time-to-exploit from weeks to days, and confirmed use means unpatched SharePoint servers are at immediate risk. The SharePoint patch belongs in the same deployment wave as the Windows driver fix.

Breaches

Malicious LiteLLM Releases Tied to Trivy Hack May Have Exposed 2,100+ Organizations Two malicious LiteLLM releases were available on PyPI for roughly forty minutes, yet the blast radius is large. They carried code that harvests cloud keys, SSH keys, Kubernetes tokens, database passwords, and other secrets from any system that installed them. CloudSEK says the dataset built from about 434,000 captured files maps potential exposure to more than 2,100 organizations. A forty-minute dwell time is an eternity when automated builds pull new versions constantly, so affected organizations should rotate every credential on those machines and audit for follow-on access.

Vulnerabilities

Adobe has shipped fixes for three CVSS 10.0 vulnerabilities across ColdFusion, Commerce, and Campaign Classic. Adobe Patches Three CVSS 10.0 ColdFusion and Campaign Classic Flaws The most severe is CVE-2026-48362, an OS command injection in ColdFusion. It can be exploited remotely with no authentication and no user interaction, executing commands in the context of the current user; the scope-changed vector means the impact can cross trust boundaries. Unauthenticated, maximum-severity command injection in an internet-facing application server gets weaponized quickly. Test and deploy the Adobe updates promptly, especially for any exposed ColdFusion or Campaign Classic instances.

Research

CERT-UA has tied a new social engineering campaign to UAC-0145, a subgroup of the Sandworm cluster. Sandworm-Linked UAC-0145 Uses Fake Job Interviews to Push VPN That Can Run Commands The lure is a fake job interview targeting IT workers in Ukraine; instead of a legitimate meeting application, targets are directed to a trojanized WireGuard installer with command-execution functionality. The campaign is notable both for its targeting — people who run networks, not random users — and for its pedigree. Nation-state actors posing as recruiters and asking targets to install a VPN client is a classic pattern, but one that remains effective. Unsolicited recruiting contacts that require installing software should be treated as a red flag.

Industry

OpenAI has released GPT-5.6-Cyber, a model built on GPT-5.6 Sol and focused on vulnerability research, penetration testing, and incident response. OpenAI Launches GPT-5.6-Cyber with Reduced Safeguards for Exploit Development The company says it is trained to improve on tasks such as finding zero-days and developing exploit chains, and to reduce refusals for certain higher-risk requests. That combination is exactly why the release is contentious. A cyber-defense assistant with fewer safeguards is also an offensive capability that lowers the barrier for less skilled attackers. Defenders will judge it on whether it improves real workflows; regulators will judge it on who gets to use reduced-refusal exploit tooling.
