Two in-the-wild exploitation stories lead: a BeyondTrust Remote Support zero-day attributed to a China-nexus espionage group, and a Collabora CODE Server flaw used to backdoor Nextcloud. Three distinct CVEs appear across the eight selected stories; none is present in CISA's KEV catalog — a confirmed catalog miss, which does not establish that exploitation has not occurred.

Actively exploited

BeyondTrust Remote Support, formerly Bomgar, was exploited as a zero-day from late August by the group reported as Armory Castle — previously tracked as UNC5221 and Warp Panda — according to China-Linked Hackers Exploited BeyondTrust Zero-Day to Take Over Remote Support Servers. CVE-2026-102764 is scored CVSS 4.0 9.3, Critical, and classified CWE-290: internal components did not adequately validate the origin of the messages they received, which NVD says could, under the right conditions, let an attacker perform file operations on the appliance. The supplied vector is network-reachable with no privileges and no user interaction required. The story text reports exploitation in the wild, while the CVE is a confirmed miss from CISA's KEV catalog.

The second is a command injection in the Collabora Online Built-in CODE Server app (richdocumentscode) for Nextcloud Hackers exploit Collabora RCE flaw to backdoor Nextcloud servers. CVE-2026-110447 is CVSS 4.0 9.2, Critical — an OS command injection in proxy.php, reachable when the CODE server isn't running, for instance just after a restart — and NVD's record describes it as exploited in the wild in September and October. Scope is narrow and worth checking: standalone Collabora Online servers are not affected, only deployments running CODE Server, and the CVSS attack-requirements field is set to Present, so exploitability depends on the appliance being in the vulnerable state.

Breaches

Burger King Japan disclosed that attackers accessed a server containing 11.18 million customer records Burger King Japan data breach exposes 11 million customer records. The Administrative Office of the US Courts, meanwhile, says a cyberattack on contractor BAE Systems took down the notice system federal bankruptcy courts use, halting nationwide noticing BAE Systems cyberattack disrupts US federal court operations. The second is the more instructive: a single supplier's compromise mapping straight onto a court function stopping. Neither story supplies an attacker, a vulnerability or a cause.

Vulnerabilities

PwnEscape, CVE-2026-99999, is a Linux kernel flaw in networking code that lets code inside a guest virtual machine read memory on the host it runs on Critical PwnEscape Linux Kernel Vulnerability Lets Guest VMs Read Host Memory. NVD describes an ipv4 checksum validation problem in which bad checksum metadata reaching the stack can let skb_checksum_help corrupt the network header. It carries a CVSS 3.1 score of 9.3, Critical, with a local attack vector, no privileges, no user interaction, changed scope and High impact across confidentiality, integrity and availability. A researcher demonstrated the leak against Vercel's live cloud sandboxes and Vercel confirmed it, per the story. Analysis: the boundary crossed — guest to host — matters more than the local vector, which reflects where the attacker must already be executing code. How broadly exploitable the flaw is in other configurations was not supplied.

Research

Citizen Lab traced infections at Al Jazeera to Candiru spyware — described in the story as an Israeli maker of spyware sold to governments — delivered through ordinary online ads and requiring no click or other action from the user Citizen Lab Traces Zero-Click Candiru Spyware Infections at Al Jazeera to Targeted Online Ads. The hidden code ran the moment an ad loaded, in some cases with the ad rendering out of sight in the background. Analysis: the delivery channel is the notable part, a mainstream ad path rather than a bespoke lure, which makes the targeting harder to spot from the victim's side. Affected devices and platforms are not stated in the excerpt.

CISA and the FBI issued a public service announcement warning election and campaign officials about cyber threats during the 2026 US midterms, flagging phishing and smishing to steal credentials and sensitive information or install malware Cyber Threat Actors Use a Variety of Techniques to Target Election and Campaign Officials. Elsewhere, Thoma Bravo-owned Proofpoint will acquire Varonis in an all-cash transaction valued at $6.3 billion, with Varonis going private Proofpoint Inks $6.3 Billion All-Cash Deal to Acquire Varonis. Analysis: credential theft remains the named electoral risk while email security spends heavily to move deeper into data security.
