Actively exploited

The most urgent item is CISA Adds One Known Exploited Vulnerability to Catalog, where CISA's Known Exploited Vulnerabilities catalog now covers three actively exploited flaws. Ray, the AI compute engine, has a critical pre-2.52.0 remote-code-execution hole reachable through a malicious website or malvertising. Its browser-attack guard is a User-Agent check that can be spoofed and combined with DNS rebinding, turning a developer who simply visits a page into a compromised build environment. MLflow, before 3.15.0, has an unauthenticated server-side request forgery: a webhook test endpoint validates the original URL but then follows redirects and re-resolves the hostname, opening a path to internal services and cloud metadata. Zimbra Collaboration Suite before 10.1.20 carries an OS command injection exploitable when the optional zimbra-snmp package is installed and SNMP notifications are enabled. The Zimbra entry needs more preconditions, but its KEV listing means attackers are already using it. For anyone running these components, the correct response is to treat them as actively targeted and patch.

Breaches

Repeated victimization is the theme in Canada’s Hospital for Sick Children attacked by cybercriminals again as employee data stolen. Toronto's Hospital for Sick Children disclosed another data theft, tied to a third-party application and involving employee data, after already absorbing a ransomware attack that disabled systems years ago. Attackers returning to a pediatric institution show that healthcare remains a favored target for its sensitive data and operational fragility.

Cloud credential hygiene is the blunt lesson in Hundreds of leaked AWS keys give full control over corporate accounts. More than 9,300 Amazon Web Services access keys exposed over about four years are still active and valid. That means full control over corporate accounts is sitting in logs, public repositories, or paste sites long after it should have been rotated. The problem is not the initial leak as much as the absence of detection and rotation.

Russian network monitoring firm confirms cyberattack claimed by pro-Ukraine hackers confirms a different kind of breach: Russian network monitoring vendor Microolap acknowledged an intrusion after pro-Ukraine group Black Spark claimed a month-long presence in its network and reached internal systems including the EtherSensor platform. A vendor whose product is network visibility losing control of its own network is both a reputation hit and a reminder that claims of long dwell time should be treated as credible until proven otherwise.

Research

Microsoft Defender's Own Driver Can Be Weaponized to Delete Security Software at Boot shows that Microsoft Defender's own signed Boot Time Removal Tool driver can be abused to perform arbitrary kernel-level file and registry operations on Windows 7 through 11 25H2. Because the driver is legitimately signed and already on disk, attackers do not need to import an external driver or exploit a software flaw. The practical risk is that security products can be deleted before the OS fully boots, leaving the system effectively blind. Defenders need boot-time visibility and should stop treating signed Microsoft binaries as automatically safe.

The npm supply chain continues to deliver working backdoors. 14 Trojanized npm Packages Drop RedC2 4.0 Linux Backdoor With AI-Assisted C2 reports 14 trojanized packages posing as calendar and streak utilities that drop RedC2 4.0, a Linux backdoor with AI-assisted command-and-control. As soon as the module loads, it finds a bundled binary, marks it executable, and launches it as a detached background process. A developer who installs a harmless-looking utility ends up with a persistent implant on a machine likely connected to source code and deployment pipelines.

AI guardrails have a blind spot, as Encrypted Prompts Bypass AI Safety Guardrails in Grok and Gemini demonstrates. The "Cryptographic Context Injection" technique hides malicious instructions inside encrypted contexts and only decrypts them inside a trusted execution environment, so safety filters see only ciphertext. The technique bypasses guardrails in Grok and Gemini. The lesson is that prompt filtering cannot rely on inspecting input text that is opaque by design.

OWASP's new AI top-10 list and Universal Skill Format give security teams a common language for AI add-on and agentic-skill risk, replacing ad hoc assessments with a structured blueprint. A standard skill format is a small but useful step toward making AI security review repeatable, just as traditional top-10 lists made web application risk easier to communicate.
