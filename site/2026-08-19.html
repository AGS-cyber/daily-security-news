Actively exploited

CISA has added four actively exploited critical flaws to its KEV catalog, covering Apple, Microsoft, and VMware software. The most detailed entry is CVE-2026-65400, an improper authentication vulnerability in Apple macOS Screen Sharing with a 9.8 CVSS score Critical macOS, SharePoint, vCenter, and Microsoft IKE Flaws Under Active Exploitation. It allows a network attacker to authenticate without valid credentials, and because CISA has confirmed exploitation, defenders should treat it as an active threat. The same batch, per reporting, includes SharePoint, vCenter, and Windows IKE flaws, making it a rare KEV update that spans collaboration, virtualization, and remote-access infrastructure. Any internet-facing deployment of these products should be patched first, and logs should be reviewed for signs of unauthorized authentication.

The KEV additions are not the only active exploitation news. Independent researchers have documented malicious scanning and exploitation against MLflow and FUXA Attackers Exploit MLflow SSRF Flaw to Steal Cloud Credentials and Secrets. In the MLflow case, an SSRF vulnerability is being used to steal cloud credentials and secrets, turning an open-source AI platform into a pivot for cloud account compromise. The FUXA activity targets a web-based SCADA/HMI system, showing that OT software is now a live target for the same scanning and exploitation tactics used against web applications. Both threads underline how open-source developer infrastructure and industrial control systems have become first-class attack surfaces, and the MLflow case in particular shows why AI platforms cannot be treated as internal tooling — any external reachability gives attackers a direct path to cloud credentials.

Breaches

Cl0p has named more than 40 victims from its campaign against the PTC Windchill platform Cl0p Ransomware Group Names Over 40 Victims of PTC Windchill Campaign, including Shell, Philips, Fiserv, Zebra, Mindray, and Largan Precision. The breadth of the list is a signal that the intrusion wave was not limited to a handful of exposed servers. It also reflects Cl0p’s extortion model: naming victims quickly creates pressure for rapid payment and complicates incident response. Organizations running Windchill should assume data may have been stolen, even if they have not yet been contacted. For anyone sharing a supply chain with the named companies, the list is also a useful input to third-party risk assessments.

Separately, the FBI and CISA have warned that Medusa ransomware has breached more than 500 U.S. critical infrastructure organizations CISA: Medusa ransomware hit over 500 critical infrastructure orgs over a multi-year campaign. That scale moves Medusa beyond a typical ransomware operation and into systemic national risk. The warning reinforces that ransomware groups are deliberately targeting sectors where downtime has physical consequences, making pre-incident prioritization and backup resilience as important as the patch queue.

Vulnerabilities

Oracle’s latest critical patch update ships 943 patches for more than 1,000 vulnerabilities across two dozen product families, more than 460 of which are remotely exploitable 943 Patches Rolled Out With Oracle’s August 2026 Security Update. The volume is unmanageable as a single event, so the focus should be on internet-facing components, identity systems, and databases first, with the rest handled on a normal lifecycle. The remote-exploit count is a reminder that Oracle estates remain a high-value target, and teams cannot prioritize what they do not know is running.

GitLab’s CVE-2026-19478 is critical in a different way. The flaw, rated 9.4 on the CVSS scale, is zero-click and can allow an unauthenticated attacker to remotely modify or delete public projects and user data through a GraphQL directive Critical GitLab Zero-Click Flaw Poses Mitigation Challenges. Affected versions are known, but public technical details are scarce, which makes detection hard for self-managed instances. The bug has not been added to KEV, but that only means CISA has not confirmed exploitation, not that exploitation has not occurred. Priority here has to be patching, even with incomplete information, while monitoring GraphQL endpoints for unusual queries in the meantime.

Research

TwinLoot Silent 'TwinLoot' Cyber Threat Operates Entirely From Microsoft's Cloud is a Python-based malware framework that operates entirely from Microsoft’s cloud, abusing SharePoint and Teams to steal credentials and establish persistence. It is a clear evolution of living-off-the-land: instead of blending in with legitimate system tools, it blends in with a trusted cloud platform. Network-level detections that catch traditional command-and-control traffic will not see it. The useful defensive response is to audit cloud API use, SharePoint site activity, and Teams integration permissions as closely as endpoint logs, and to treat cloud logging as a security control rather than compliance overhead.
