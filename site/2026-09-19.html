Standfirst: Three confirmed-exploited stories dominate — Cisco's 10.0 ISE authentication bypass, Linux kernel flaws newly added to KEV, and a pre-auth RCE in a workflow platform — while a 23.6-million-record breach and two enterprise patches fill out the rest.

Actively exploited

Start with the one that scored the maximum. CVE-2026-76460 in Cisco Identity Services Engine carries a 10.0 CVSS score, and the vector leaves nothing out: network-reachable, no privileges required, no user interaction, scope-changed, full impact across confidentiality, integrity and availability Cisco Zero-Day Highlights API Endpoint Authentication Issues. The root cause is insufficient authentication control on an API endpoint — CWE-648, incorrect use of privileged APIs — meaning a crafted request bypasses authentication and reaches the device without ever satisfying the web management interface. It is in KEV, with a short federal remediation window attached. The supplied affected configurations span ISE 3.1.0 from base through patch 11, and 3.2.0 through patch 10. ISE is the component that decides who joins the network; an auth bypass there is a beachhead into identity infrastructure, not a single bad appliance. Two practical notes: internet exposure is usually accidental rather than deliberate (guest portals, remote-access portals, stale NAT rules), and an authentication bypass means your logs will show successful-looking access.

The three Linux kernel flaws added to KEV deserve attention for a different reason CISA Flags Three Linux Kernel Vulnerabilities Exploited in the Wild. The one detailed here, CVE-2025-39682, is a mishandling of zero-length records on the TLS receive path's rx_list, classified as CWE-754 — improper check for unusual or exceptional conditions. NVD scores it 7.1, and its vector is local rather than remote, which is exactly the sort of number people use to defer action. Don't. KEV membership is a statement about observed exploitation, and local-root primitives are the payload half of container escapes, privilege-escalation chains and post-intrusion persistence. The affected ranges are broad: kernels from 6.0 up to but excluding 6.1.149, 6.2 to before 6.6.103, 6.7 to before 6.12.44, and 6.13 to before 6.16.4, plus the 6.17 release candidates, with Debian 11.0 named as well. Your distribution will backport; your job is knowing which fleet kernels still sit inside those windows.

Then there is Orkes Conductor, where CVE-2026-58138 is reported exploited in the wild before authentication ever happens Critical Pre-Auth RCE in Orkes Conductor Workflow Platform Exploited in the Wild. Version 3.21.21 through anything before 3.30.2 is affected: an attacker submits an inline workflow definition containing malicious JavaScript or Python expressions to the workflow API endpoint, and the platform's unsandboxed GraalVM evaluators — configured with HostAccess.ALL or allowAllAccess(true) — execute it through INLINE, LAMBDA, DO_WHILE and SWITCH task types, reaching OS commands by reflection or direct subprocess call. Scores are 9.8 on CVSS 3.1 and 9.3 on CVSS 4.0, CWE-94. What makes this worse than the score is position: workflow engines hold integration credentials, service tokens and the keys to everything they orchestrate. Note also that it is not in KEV — a confirmed catalog miss alongside reported exploitation, which is the cleanest possible demonstration that catalog absence proves nothing.

Breaches

One server-side flaw was enough at Gyazo, where 23.6 million user records were taken Gyazo server flaw exploited to steal 23.6 million user records. There is no CVE or vendor advisory metadata to reason about here; the lesson is the ratio. A single defect in a server component, against an account base of that size, converts one unpatched machine into a consumer-scale breach with the attendant credential-reuse fallout across other services. Worth using as a planning question rather than a postmortem: if one server in your estate fell tomorrow, how many records would that represent?

Vulnerabilities

SolarWinds has patched a hard-coded key in Access Rights Manager, CVE-2026-28326, rated 8.8 and rooted in CWE-321 SolarWinds Patches ARM Hard-Coded Key Flaw Enabling Unauthenticated RCE. The description is blunt — a static key in a product that brokers privileged access — and everything from version 2026.2 backwards is affected. It is not in KEV, and the CVSS vector is adjacent-network rather than internet-wide, so exposure depends on who can reach the service. Both facts should temper urgency, not cancel it: privilege-management tooling is a deliberate target, and a static key cannot be rotated out of trouble.

WordPress shipped core patches for a chain its reporters call Click2Shell New WordPress Click2Shell Flaw Forces Theme Installs, Can Chain to Code Execution. The core flaw lets a crafted link, opened by an already-authenticated administrator, install a theme from the official WordPress.org directory without anyone pressing Install; chained, that reaches code execution. No CVE is supplied, so prioritise by exposure instead: the attack needs a logged-in admin to click, and its trust boundary is the interesting part — a trusted directory, a legitimate session, and a URL. Patch core on any site an administrator logs into.

Industry

A joint law enforcement advisory attributes a sprawling campaign to North Korea's WaterPlum, which compromised at least 30,000 devices between December 2025 and July 2026 and moved more than $10.7 million in stolen cryptocurrency back to the country North Korean WaterPlum hackers infected 30,000 devices worldwide. The scale is the story: this is volume-driven criminal infrastructure funding a state, and the operational takeaway is that endpoint compromise in service of cryptocurrency theft is now a mass-market problem, not a targeted one.

Research

Finally, a chain worth studying rather than fearing: researchers used Claude Opus 5 to link two flaws and take over the ChatGPT and Codex accounts of several OpenAI employees, then reach an internal code repository Claude Opus 5 Helped Researchers Take Over OpenAI Staff Accounts via Chained Flaws. It began with a bug in the software running OpenAI's public help forum and moved through a weakness in the login system — sanctioned research, disclosed as such. Two lessons. Model-assisted offensive work visibly compresses the effort needed to stitch minor defects into a full chain. And the seam was not the flagship product: it was community infrastructure and the identity layer bridging it to everything else.
