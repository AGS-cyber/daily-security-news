Actively exploited

Citrix disclosed eight vulnerabilities across NetScaler ADC and NetScaler Gateway, and CISA has added Critical Zero-Day Vulnerabilities Exploited in Citrix NetScaler ADC, Gateway's CVE-2026-88771 and CVE-2026-88772 to the Known Exploited Vulnerabilities catalog on confirmed in-the-wild exploitation, with a compressed federal remediation window attached. Both carry a CVSS 4.0 score of 9.5. CVE-2026-88771 is an improper input validation flaw (CWE-20) that lets an unauthenticated attacker execute arbitrary commands; CVE-2026-88772 is a memory buffer restriction failure (CWE-119) leading to remote code execution or denial of service. Affected configurations span ADC and Gateway before 14.1-73.37 and 13.1-64.23, including the FIPS and NDcPP builds — which is the part that trips up teams who upgrade the mainline appliance and forget the hardened variant running the same exposed VIP.

The mistake to avoid is patching the two KEV entries and stopping there. The same advisory carries a 9.3 request-smuggling flaw (CWE-444), three memory-overflow issues at 8.8, and a 7.0 policy bypass, none of which appear in KEV. A confirmed catalog miss is not evidence that exploitation hasn't happened, and an internet-facing ADC is exactly the asset where an attacker chains a smuggling primitive into something worse. Treat the whole set as one remediation unit, and assume any appliance that has been internet-exposed since the disclosure warrants a forensics pass rather than just a reboot into a new build.

The second live campaign is Google Warns of ShinyHunters’ Fresh Oracle PeopleSoft Campaign: ShinyHunters has modified its exploit against Oracle PeopleSoft CVE-2026-35273 and is running a fresh extortion wave. That flaw is already in KEV with known ransomware campaign use, a CVSS 3.1 base score of 9.8, and a missing-authentication-for-critical-function weakness (CWE-306) affecting PeopleTools 8.61 and 8.62 — unauthenticated network access over HTTP is enough for full takeover. The detail that matters defensively is "modified exploit." When an operator changes tooling mid-campaign, signature and IOC-based detections built for the first wave degrade, so detection should lean on behavior around the PeopleSoft web tier: unexpected POSTs to update-related components, new administrative accounts, and outbound traffic from the middleware host. If PeopleSoft is internet-facing and unpatched, that is not a backlog item.

Breaches

Bitget Says Attacker Exploited Third-Party Security Product Flaw to Steal $388M is the day's most instructive loss. Bitget attributes the theft of roughly $388 million to a vulnerability in a third-party security product the exchange relied on, which the attacker used to obtain high-level internal credentials and then issue fraudulent withdrawal commands to the wallet system. No CVE is attached, and that absence is itself the finding: this was a privilege-path failure, not a patch-management failure. Any vendor sitting inside your trust boundary with the ability to read secrets or broker authentication is a credential source, and the blast radius of that vendor's flaw is whatever those credentials can reach. For exchanges and anyone else holding custodial assets, the control that would have helped is not another scanner — it is scoping, segregating, and rate-limiting the authority that internal credentials carry into withdrawal and signing paths.

JADEPUFFER-Linked Attackers Used Compromised Service Principals to Delete Azure Resources describes the cloud-native version of the same problem. Microsoft tracks JadePuffer, also called Storm-3168, orchestrating destructive actions inside an Azure environment using compromised service principals over an intrusion lasting about eighteen hours. Service principals are non-human identities: frequently over-permissioned, rarely rotated, and outside the reach of phishing-resistant MFA. An attacker who lands one inherits its role assignments immediately, and the destruction phase can begin without any interactive logon to alert on. Enumerate service principals with owner or contributor rights, look for credential additions and role-assignment changes, and treat Azure Activity and Entra audit logs as your primary detection surface here, not endpoint telemetry.

Chrome Store Hosts 'Poper Blocker' Spyware Downloaded by Millions is a reminder that marketplace approval is not a security control. A purported ad-blocker with millions of installs and a store listing is alleged to be exfiltrating reams of sensitive data while benefiting from platform approval despite earlier researcher warnings. Browser extensions run with the user's session, read what the user reads, and are almost never inventoried. If you cannot produce a list of extensions installed across the fleet, you cannot assess this exposure at all.

Industry

New Mexico jury finds Meta deceived consumers about data privacy practices moves platform accountability from regulator to jury: a New Mexico jury found Facebook violated the law nearly 44 million times over misrepresentations about its data privacy practices. For security leaders the implication is narrower than the headline and more uncomfortable — public statements about how data is collected, protected, and shared are now litigable artifacts. Marketing language, privacy policies, and trust-center claims all deserve the same review as a disclosure filing, because the gap between the claim and the practice is precisely what gets measured per user, per violation.

Research

Two research pieces are worth an analyst's time for opposite reasons. NeedyMantis: Unpacking a post-compromise malware family used in targeted operations unpacks NeedyMantis, a modular post-compromise malware framework built from custom loaders, encrypted archives, and extensible components designed to hold long-term access and support follow-on operations. That structure is the point: encrypted archives and swappable components defeat static indicators, so hunting should target loader behavior and archive handling rather than hashes. Assume that where NeedyMantis is present, the initial access is old and the operator intends to stay.

RatHat Android Malware Console Uses Gemini to Identify Higher-Value Victims shows how cheap the other end of the market has become. RatHat operators build and publish an Android banking trojan, then control infected phones from a web console, tallying nearly a hundred console deployments in a malware-as-a-service model where each customer runs a separate copy. The novelty is the triage layer: Gemini is used to rank victims by value, which turns a blunt collection tool into a prioritized target list for follow-on fraud. Mobile remains the least-instrumented endpoint in most enterprises, and this is what industrializing that blind spot looks like.
