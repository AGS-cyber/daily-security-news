Two confirmed-exploited flaws and a supply-chain script hijack dominate: a month-long campaign against MSP-run ScreenConnect servers, an Optimizely compromise that pushed skimmers and iOS exploit code across hundreds of sites, and a KEV-listed Brotli bug that has turned up in a Siemens industrial advisory. The breach, research and patch stories below round out what deserves attention.

Actively exploited

More than 40 MSP-run ScreenConnect servers absorbed over 688,000 requests in a month-long campaign abusing CVE-2026-84869 to execute files pushed from a guest session MSP ScreenConnect Servers Targeted in Month-Long Campaign. The flaw is KEV-listed with exploitation confirmed and rated 9.9 Critical (CVSS 3.1) for improper privilege management and missing authorization; the vector needs low privileges and an active remote session, so it is not pre-authentication. One conflict in the supplied records is worth flagging: the campaign hit servers, while the NVD description places the condition in the client and states that servers are not impacted. Affected versions run below 26.6.5.9742, and CISA's federal remediation deadline has already elapsed.

Separately, an attacker exploited a flaw in Optimizely Web Experimentation to plant code in the scripts customers load from the service, so visitors to sites run by at least 178 organisations — among them CNN, the BBC and Zoom — received it Hijacked Optimizely Scripts Served Card Skimmer and iOS Exploit Kits to CNN, BBC and Zoom Visitors. The payload combined a card skimmer with iOS exploit kits. No CVE was supplied for the Optimizely flaw, and the excerpt does not describe how the attacker reached it.

Node2Shell, tracked as CVE-2026-111497, keeps widening. The Brotli decoder out-of-bounds write — 9.2 Critical under CVSS 4.0, reachable by a remote unauthenticated attacker through a crafted compressed stream, with memory disclosure, denial of service and possible code execution — is KEV-listed with exploitation confirmed and now features in a Siemens advisory covering industrial automation products Siemens Industrial Automation Software Products. Affected ranges span Brotli 1.0.3 through 1.2.0 (fixed in 1.0.10, 1.1.1, 1.2.1), several Node.js branches, .NET 8 through 10, brotlicffi and Debian 12. The excerpt does not name the specific Siemens products; treat the advisory as a prompt to inventory bundled decoders, not a complete list.

Vulnerabilities

N-able's critical N-central hotfix addresses 17 flaws, a mix of recently disclosed zero-days and vulnerabilities already exploited in the wild, and the vendor is retiring legacy APIs alongside it N-able Kills Legacy APIs, Patches 17 N-central Zero-Days. No CVE identifiers or severity values were supplied, so treat the count as the vendor's grouping rather than a scored set.

Oracle is preparing Java SE patches for 11 vulnerabilities, all remotely exploitable without authentication and carrying a maximum CVSS 3.1 score of 8.1 per the advance notice, while separate reports warn of a potentially critical OpenJDK remote code execution flaw tracked as CVE-2026-114938 Oracle to Patch 11 Java Flaws Today as Critical OpenJDK RCE (CVE-2026-114938) Report Emerges. That CVE has no NVD record in the supplied intelligence and is not KEV-listed, so its "critical" billing rests on the reports rather than a scored entry — and it is distinct from the 11 issues being patched. Prioritisation: the patch batch is scored and imminent; the OpenJDK report is of unconfirmed severity.

California is suing OpenAI, seeking court-ordered changes after the Hugging Face hack, alleging the company misled and endangered the public and its users by knowingly developing advanced models without necessary safeguards California Sues OpenAI, Seeking Court-Ordered Changes After the Hugging Face Hack. The allegations are untested, and the excerpt does not detail the Hugging Face incident or the specific safeguards at issue. Analysis: the case matters less for its merits than for whether courts begin setting baseline safeguard expectations for model developers whose platforms are abused — an outcome the supplied text does not predict.
