Eight stories, four distinct CVE records, and an unusually clean split between what is being exploited right now and what is merely reported. Microsoft has confirmed credential theft through Azure API Management, ConnectWise ScreenConnect is being abused inside MSP tooling, CISA has added two more flaws to its known-exploited list, and researchers are warning about a legacy ASP.NET library that will not die. Below that: a confirmed utility breach, a reported FBI database incident, a $44bn vendor consolidation and suspected China-aligned persistence tooling.

Actively exploited

Microsoft is warning that a vulnerability in Azure API Management Classic tiers was exploited to steal stored API credentials, with Norwegian authorities linking the flaw to cyberattacks against energy companies Microsoft Azure flaw exploited to steal customers' API credentials. The detail that matters is what was taken: credentials held by the service, not merely data passing through it, which puts the risk downstream of Azure itself. The excerpt does not say how many customers were affected or which credentials were exposed, so scope remains unknown. Analysis: secrets theft against a cloud gateway serving critical infrastructure is the highest-leverage item today, because rotation and blast-radius assessment, not patching alone, is the real work.

ConnectWise ScreenConnect is the second live intrusion path. CVE-2026-84869 carries a CVSS score of 9.9 and is KEV-listed, and the flaw sits in the client: per the supplied description, files can be transferred and executed through an active remote session without authorization or host confirmation, with servers unaffected. The vector requires low privileges, so this is an attacker who already holds a guest position in a session rather than an anonymous internet user — but the payoff is a connecting technician's host, which is why activity against MSP servers matters far beyond one customer Hackers Exploit Critical ScreenConnect Flaw to Hijack MSP Technician PCs Without Warning. Affected configurations run below 26.6.5.9742. CISA's remediation requirement is scoped to federal agencies under its risk-based patching guidance; it is not a universal deadline.

CISA's two additions both carry federal remediation requirements and both deserve attention outside government. CVE-2026-133968 in Project MONAI's MONAI Label is a critical 9.8 path traversal, reachable unauthenticated over the network via the image parameter to the datastore image endpoint, turning directory traversal into remote code execution, with versions before 0.8.6 affected and the NVD description stating in-the-wild exploitation CISA Adds Two Known Exploited Vulnerabilities to Catalog. The second, CVE-2026-134624 in N-able MailAssure, is a critical 9.3 SSRF, but the prerequisites are different and worth stating precisely: it requires an authenticated, highly privileged API user, who can then direct the server to probe and send crafted data to arbitrary internal hosts and ports. Stolen or over-broad API keys are the enabling condition, not anonymity.

Then there is CVE-2026-131914: a critical 9.3 deserialization flaw in the legacy Idunno.AntiCsrf ASP.NET library, affecting versions through 0.9.1 Beta, allowing unauthenticated code execution via object injection, which researchers say has already been exploited and which they want removed from circulation entirely Hackers Exploit Critical ASP.NET Anti-CSRF Library Flaw Allowing Unauthenticated RCE. It is not in the KEV catalog — a confirmed catalog miss, which says nothing about whether exploitation is happening. The practical problem is inventory: a DLL nobody remembers referencing is exactly the dependency that survives cleanup.

Breaches

KEPCO has confirmed an intrusion into its internal network, with a threat actor reaching two systems holding customer, employee and contractor data, in an incident affecting 1.5 million people South Korea’s power giant KEPCO confirms data breach impacting 1.5 million. A breach touching all three population types simultaneously is the shape that complicates notification and credential-reset planning. Separately, the FBI is reportedly investigating a data breach involving the National Crime Information Center, described as a second such incident FBI reportedly facing second data breach involving National Crime Information Center; that reporting remains unconfirmed and the supplied excerpt gives no details on what was accessed. Treat the first as established and the second as a claim under investigation.

Industry

CrowdStrike's $44 billion acquisition of Zscaler would combine endpoint protection with zero-trust network security, with the stated aim of gaining greater control over AI agents CrowdStrike Makes AI Security Push With Blockbuster Zscaler Deal. Analysis: the strategic logic — one policy plane across endpoint and network for agent traffic — is coherent, but the buying implication for CISOs is consolidation risk and roadmap uncertainty, and the deal's completion and terms beyond the headline figure were not supplied.

Research

Webworm, described as a China-aligned actor, is suspected of using a custom build of the open-source SoftEther VPN Bridge that strips recognizable detection fingerprints, implements tricks to hide from security tools, and masquerades as network-monitoring software to hold covert remote access Webworm Suspected of Modifying SoftEther VPN to Evade Detection and Hide Remote Access. The attribution and the tooling link are both framed as suspected in the supplied material; treat them as such. The detection angle is the concrete takeaway: hunting for known SoftEther artefacts will miss a build designed to remove them.
