A maximum-severity GitLab flaw already exploited against Alpine Linux, active Drupal Commerce Core exploitation and mass WordPress scanning dominate the vulnerability agenda, while Binance discloses a multi-billion-dollar security incident and a trojanized AI coding extension exposes developer supply-chain risk. Cisco SD-WAN and TeamViewer flaws and an FBI seizure round out the picture.

Actively exploited

GitLab CE/EE contains a CVSS 10.0, unauthenticated remote code execution flaw, CVE-2026-97229, fixed in 19.2.8, 19.3.5 and 19.4.2; the supplied NVD entry ties it to insufficient validation of a specially crafted regular expression in CI/CD configuration. It is confirmed in CISA KEV and the source reports exploitation against Alpine Linux; the supplied CVSS vector indicates no privileges or user interaction are required Max-Severity GitLab Vulnerability Exploited Against Alpine Linux.

Drupal Commerce Core’s missing-authorization flaw, CVE-2026-118539, affects versions 0.0.0 through 2.41 and 3.0.0 through 3.3.13; Drupal warns it is being actively exploited, though no CVSS value is supplied and CISA KEV enrichment shows no catalog match Hackers Actively Exploit Highly Critical Drupal Commerce Core Authorization Bypass Flaw.

WordPress Core versions 4.7 through 7.1.3 face a high-severity RCE, CVSS 8.1 and no CVE identifier, with nearly 63,000 attack attempts in 24 hours shortly after patches appeared WordPress RCE Flaw Draws Nearly 63,000 Attack Attempts in Just 24 Hours. Analysis: the attempt count indicates mass scanning, not necessarily successful compromise; the source does not supply exploit prerequisites.

Breaches

Binance says a security incident affected about $6.3 billion in assets, with nearly $3 billion frozen on-chain; Tether and Circle froze more than 1.567 billion USDT and 800 million USDC respectively Binance Suffers Security Breach Affecting $6.3 Billion in Assets, Nearly $3 Billion Frozen. The supplied account gives no cause, attribution or customer-loss confirmation; the operational question is how much remains exposed. Analysis: the stablecoin freezes are the clearest containment lever described, but they do not establish a root cause.

Separately, a malicious version of Anthropic’s Claude Code VS Code extension was distributed through Cursor’s marketplace for about 11 hours, exposing up to 5,000 developers to malware that installed persistent SSH backdoors Malicious Claude Code extension on Cursor planted SSH backdoors. No CVE or technical root cause is supplied. Analysis: the incident makes AI-assisted development tooling a supply-chain target; the source does not say whether the backdoors were used.

Research

UAT-11473, described as a newly identified APT group, exploited CVE-2026-20127 in Cisco Catalyst SD-WAN Controller, Manager and Validator to deploy a custom KeyDrift framework Hackers exploit Cisco SD-WAN flaw to deploy custom KeyDrift malware. The authentication bypass is CVSS 10.0, unauthenticated and remote, and can yield internal high-privileged access and NETCONF configuration control; CISA lists it in KEV, and the supplied NVD ranges cover multiple releases, including branches before 20.9.8.2 and 20.16 before 20.18.2.1. Analysis: pairing a control-plane bypass with bespoke malware suggests the access is being used for persistence, not just initial entry; the source does not describe KeyDrift’s capabilities beyond the framework label.

Vulnerabilities

TeamViewer Full Client, Portable and Remote Control App before 15.83 contain CVE-2026-111585, an integer overflow in remote-control screen processing rated CVSS 8.8 High TeamViewer Flaw Could Let Malicious Hosts Take Over Support Technicians’ Machines. Exploitation requires the user to establish a remote-control session to an attacker-controlled or compromised host and can cause denial of service or, depending on platform, code execution with viewer privileges. The flaw is not listed in KEV. Analysis: the direction of attack turns a support session against the technician’s machine, but the user-initiated session requirement limits mass exploitation.

Industry

The FBI seized the domain of Virtualine, a bulletproof host that the source says catered to hack-for-hire services, supported ransomware and infostealer operators, and accepted crypto payments Bulletproof Host Virtualine Loses Its Domain to FBI Seizure. No arrest, charge or customer count is supplied. Analysis: domain seizure disrupts a named service but does not by itself show the underlying criminal operations have been dismantled.
