CISA added four actively exploited flaws to its Known Exploited Vulnerabilities catalog and separately listed a SonicWall SSLVPN bypass, while exploitation also hit QNAP NAS devices and Keplr wallets. France attributed disruptive retail refrigeration attacks to Iranian state-backed hackers, N-able pulled hosted N-central offline over published alleged zero-days, and researchers described an AI-agent intrusion into Taipei dispatch records.

Actively exploited

CISA added four flaws to KEV on evidence of active exploitation: GPUStack improper authentication (CVE-2026-102895, 9.8 Critical), FreeSWITCH code injection (CVE-2026-116779, 9.8 Critical), OpenSSH password authentication bypass (CVE-2026-123158, 8.1 High) and IBM Aspera Faspex incorrect authorization (CVE-2026-123218, 9.8 Critical) CISA Adds Four Known Exploited Vulnerabilities to Catalog. Three are Critical, but the set is mixed, not uniformly so. GPUStack before 2.2.0 let unauthenticated remote requests gain administrator access by appearing to come from loopback; exploitation was observed against a 2.1.1 deployment. FreeSWITCH before 1.11.3 let a peer whose SIP MESSAGE was accepted reach API command execution; exploitation was observed. OpenSSH before 10.6p2 on Linux with musl libc and no PAM can accept any 256–1024-character password for some account configurations. Aspera Faspex 5.0.0–5.0.19 lets an authorized user craft a message to gain full administrative privileges. CISA's federal remediation deadline applies to federal agencies, not every organization.

CISA also listed CVE-2026-19868, a 7.5 High SonicOS SSLVPN authentication-enforcement flaw, after reports it may have been exploited CISA Flags SonicWall SonicOS MFA Bypass Flaw Amid Reports of Possible Exploitation. A user with valid credentials for an alternate authentication method can bypass SAML controls and SAML-enforced MFA; affected SonicOS is before 7.3.4-7015.

Plex2Shell, a four-flaw chain against Plex Media Server on QNAP NAS devices, is being exploited, although the excerpt supplies no CVE IDs, affected versions or patch details Plex2Shell Exploited Against QNAP NAS Users.

Some Keplr wallets created with Google or Apple sign-in were drained after an attacker exploited a Web3Auth flaw; Web3Auth then used the attacker's route to empty other at-risk wallets, the companies said Web3Auth Flaw Exploited to Steal Keplr Crypto, Provider Empties Other Wallets for Safety. The flaw and affected configurations were not supplied.

Breaches

An attacker broke into AWS accounts belonging to multiple Qubole customers, stealing stored secrets and data, according to Wiz Hackers Exploit Qubole's Trusted AWS Access to Breach Customer Accounts and Steal Data. The attacker used credentials for an AWS account that Qubole's platform uses to reach customers; how those credentials were obtained has not been disclosed. Qubole is a data lake platform owned by Idera. The excerpt does not give customer counts, data types or notification status. Analysis: this is a third-party trust failure, with Qubole's cross-account access as the path, but initial access remains unknown.
