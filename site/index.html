A KEV-listed ConnectWise ScreenConnect flaw is being exploited via a recovered attacker toolkit, Maersk has confirmed data theft, and attackers are chasing N-able N-central zero-days. Apache and PTC shipped critical fixes, a stolen-credential campaign planted a CI secret stealer across GitHub repositories, researchers described autonomous AI-agent intrusions, and a nine-country operation seized malware infrastructure.

Actively exploited

The ScreenConnect campaign exploits CVE-2026-84869, a now-patched critical flaw with a CVSS 3.1 score of 9.9, rather than a new vulnerability, according to the supplied account SCKit Malware Turns ScreenConnect Support Sessions Into Potential MSP Attack Paths. The recovered toolkit targets ScreenConnect support sessions, and the flaw is KEV-listed. NVD describes a client-side condition that may allow files to be transferred and executed through an active remote session without authorization or host confirmation in certain circumstances; servers are not impacted. The vector requires network access, low privileges and no user interaction, with scope changed. CISA's required action is to apply mitigations per vendor instructions and BOD 26-04, including evaluating internet exposure; its federal due date is not a universal deadline. The MSP concern is that support sessions can become an attack path.

Attackers are also targeting N-able N-central zero-days after a researcher disclosed more than 30; N-able patched the unauthenticated ones Hackers Target N-central Zero-Days as N-able Rushes Patches. No CVE identifiers, affected versions or exploitation prerequisites were supplied, leaving the practical exposure unclear.

Maersk confirmed data theft amid a $5 million extortion attempt, while the WhiteArmor ransomware group claims it stole 100GB Maersk Confirms Data Theft Amid $5 Million Extortion Attempt. The confirmation of theft and the group's volume claim are separate facts; no intrusion vector or affected systems were supplied.

An attacker used stolen credentials for 4,837 GitHub accounts to plant a CI secret stealer in repositories those accounts could write to, with execution in at least 1,806 repositories Attacker Used 4,837 Hijacked GitHub Accounts to Run a CI Secret Stealer in 1,806+ Repositories. The stealer targets secrets and cloud credentials reachable by CI workflows. The excerpt indicates likely collection but is truncated, so the full credential exposure is not established.

Vulnerabilities

Apache HTTP Server's mod_http2 has a critical flaw, CVE-2026-119618, that could let unauthenticated remote attackers execute code Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely. It affects 2.4.55 through 2.4.70 and is fixed in 2.4.71; only HTTP/2-enabled servers are affected. NVD maps it to CWE-362, improper synchronization in assign_headers(), but supplies no CVSS score, so the critical label comes from the source description rather than an enriched CVSS value.

PTC has patched a critical remote-code-execution flaw in Windchill and FlexPLM, CVE-2026-126325, scored 9.2 under CVSS v4 PTC Patches Critical Windchill and FlexPLM Flaw That Could Enable Remote Code Execution. It involves improper input validation and deserialization of untrusted data. The vector shows network reachability, no privileges and no user interaction, but high attack complexity. No affected versions or exploitation evidence were supplied, and it is not in KEV.

A research account describes attackers using the open-source Cairn AI agent framework to autonomously breach semiconductor, defense and civil-society targets Attackers Use Autonomous AI to Target Semiconductor, Defense and Civil Society Sectors. Analysis: if borne out, the significance is operational—agentic execution compressing intrusion steps—but the supplied evidence is a summary, not a technical proof set.
