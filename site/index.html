Attempted exploitation of an OpenSSH authentication bypass began within hours of disclosure, with one honeypot rooted, while QNAP and WordPress users face live attacks and Barracuda patches an unauthenticated root chain.

Actively exploited

Threat actors began attempting to exploit CVE-2026-123158, an OpenSSH authentication bypass nicknamed SSHole, within hours of disclosure, and one honeypot was rooted, according to Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot. The High-severity flaw (CVSS 8.1) affects Linux systems running OpenSSH on musl libc without PAM; NVD says some account configurations accept any password between 256 and 1,024 characters, and the excerpt notes sign-ins to accounts with no password set. Analysis: the narrow configuration still leaves exposed musl-based servers the story to watch.

QNAP says hackers are exploiting the Plex2Shell vulnerability chain against NAS devices and urges users to update Plex Media Server to the latest version in the QNAP App Center QNAP says hackers breaching NAS devices in Plex2Shell attacks. The supplied excerpt gives no CVE, affected versions or post-exploitation detail, so exposed appliances remain the immediate concern.

Sites running an actively exploited WordPress flaw can be exposed again while installing the fix, because the update unpacks files using the site's old, unpatched code; an attacker who strikes at the right moment can run code on the server Installing the Fix for an Exploited WordPress Flaw Can Expose Some Sites One Last Time. Analysis: the patch window itself becomes part of the incident response.

Breaches

Chainalysis says an attack on its systems and internal tools exposed credentials and live tokens for all customers Chainalysis says breach exposed credentials for all customers. Analysis: that makes it a customer-wide credential problem, not just a vendor incident.

Vulnerabilities

Barracuda's Email Security Gateway has two flaws that researchers chained to run commands as root with no login; patches are available and the chain has been detailed publicly Experts Demonstrate Barracuda Email Security Gateway Chain Enabling Root Access Without Login. The named flaw, CVE-2026-116606, is Critical (CVSS 9.3) in versions earlier than 9.4.0.030: an unauthenticated remote attacker can invoke a configuration-import function and restore a crafted backup archive, modifying the appliance's global configuration. The second flaw and the chain's full prerequisites were not supplied.

D-Link has published mitigation measures for multiple unpatched zero-days in DGS-3130 series managed switches, with no patches supplied in the excerpt D-Link warns of multiple zero-days in DGS-3130 Series switches. Analysis: for those models, mitigation is the only near-term defense.

Industry

The FBI and CISA warn that hackers are actively targeting industrial refrigeration and cold-chain monitoring systems worldwide, with potential food spoilage, equipment damage and fire hazards FBI, CISA warn of cyberattacks targeting refrigeration systems. Analysis: that puts physical safety and supply-chain continuity, not just data confidentiality, in the threat model.

Research

APT29, described as Russian state-sponsored, is compromising websites, fingerprinting visitors and harvesting information from the interesting ones, in a campaign targeting thousands of mobile users APT29's Watering Holes Target Thousands of Mobile Users. Analysis: the mobile focus suggests watering-hole tradecraft tuned to a different endpoint.
