Two stories dominate: reportedly exploited PHP flaws that enable unauthenticated remote code execution, and a 286-fix Apple release that backports a zero-day patch to older iPhones. Behind them sit a fixed Android Authenticator token-theft flaw, a botnet disruption, a long-running espionage campaign and two breach disclosures.

Actively exploited

CISA has confirmed in-the-wild exploitation of the "PHP2Shell" flaws and added them to its Known Exploited Vulnerabilities catalog, according to CISA Confirms Active Exploitation of Two PHP2Shell Flaws Enabling Remote Code Execution; both are rated 9.2. One caveat worth flagging: the supplied enrichment for CVE-2026-109618 returned no KEV record, so treat catalog membership as reported by the story rather than corroborated by the structured data. Only one of the two CVE identifiers appears in the supplied excerpt — the second is truncated — so the description below covers that one flaw. CVE-2026-109618 is a memory-handling bug: PHP's longjmp() path for out-of-memory errors can leave request memory uninitialized, and request cleanup may then read or branch on it, leading to RCE. The CVSS 4.0 vector is network-reachable with no privileges and no user interaction, but carries high attack complexity — reliably triggering the condition is not trivial. Affected ranges are PHP 7.3.0 up to before 8.2.35, 8.3.0 before 8.3.36, 8.4.0 before 8.4.27 and 8.5.0 before 8.5.12; the NVD configuration list also sweeps in Siemens Ruggedcom APE1808 firmware and a run of PAN-OS builds, which is worth checking against your own estate rather than assuming PHP-only exposure.

Apple's iOS and macOS 27.2 release fixes 286 vulnerabilities and brings the fix for an exploited CoreGraphics flaw to older iPhones via iOS 18, iOS, macOS 27.2 Patch 286 Bugs; Fix for Exploited Flaw Backported to iOS 18. No CVE identifiers or exploitation details were supplied, so the practical point is coverage: the patch is not limited to the newest hardware.

Vulnerabilities

CVE-2026-80097 in Microsoft Authenticator for Android is an improper-authentication flaw (CWE-287) rated 8.6 High, with a CVSS 3.1 vector of local attack, low complexity, no privileges, user interaction required and scope changed Microsoft Authenticator Flaw Let Permissionless Android Apps Steal Work Account Tokens. In the researchers' tests, a malicious app holding no permissions could pose as a trusted Microsoft app such as Teams and collect sign-in tokens for a victim's work account. Fixed in Authenticator 6.2606.4246. Two things are easy to garble here: the vector is local with user interaction, so this is not a remote zero-click compromise, and the KEV lookup is a confirmed miss — which does not establish that exploitation has not occurred. For BYOD fleets, the update is the whole control.

Industry

Australian Signals Directorate operators gained access to a criminal's Amadey backend and disconnected that controller from 180,000 infected computers worldwide, including machines in Australia Australia Gets Into Amadey Malware Backend, Cuts Off Access to 180,000 Infected Computers. Analysis: this is a disruption of one operator's access rather than demonstrated cleanup of the bots, and the supplied text does not say whether those hosts were remediated or simply orphaned — a distinction that matters for anyone tracking follow-on infrastructure.

Research

The North Korea-linked Lazarus Group has been attributed to an espionage campaign dubbed Operation FlashHole, targeting at least three South Korean organisations across construction, software, and wire-communication equipment manufacturing, active since at least July 2025 according to Kaspersky Lazarus Abuses South Korean Security Software to Deploy Malware Using Post-Quantum Encryption. The campaign abuses South Korean security software and post-quantum encryption. The attribution is the source's; the operational lesson is the familiar one about locally trusted tooling as a supply-chain foothold.

Breaches

ENGIE confirmed that attackers stole customer data after breaching a marketing platform used by its business partners; no affected population or data categories were supplied Energy giant ENGIE discloses data breach affecting customers. The University of Copenhagen confirmed hackers accessed a test environment containing personal data belonging to 525,000 people University of Copenhagen data breach exposes data of 525,000 people.
