CISA's confirmation that an unauthenticated WordPress Core race condition is being exploited in the wild leads a day otherwise dominated by breaches: altered refrigeration settings at a French blood service, a nine-figure bank theft traced to a supplier, and Binance's own account of a fake-interview malware chain.

Actively exploited

CISA added CVE-2026-119977, a WordPress Core TOCTOU race condition, to its KEV catalog citing evidence of active exploitation CISA Confirms Hackers Exploiting WordPress Core Flaw During Software Upgrades. Scored 8.1 HIGH (CWE-367), it stems from predictable, web-accessible staging paths used during full-package core upgrades, and the NVD description says unauthenticated attackers can execute code on the server during the upgrade window. The vector is network-reachable with no privileges or user interaction required, but high attack complexity — exploitation depends on hitting an upgrade in progress, not a fire-and-forget request. Supplied affected ranges run from 4.7 through the 6.6 branch, each with its own fixed release; the description's reference to versions up to 7.1.3 does not match those ranges, so verify against the vendor advisory. CISA's required action cites BOD 26-04 and forensics triage guidance, with a due date that binds federal agencies only. Analysis: for a platform this ubiquitous, KEV status moves this from the monthly patch cycle to this week, and upgrade logs are worth a look.

Breaches

France's national blood service said a cyberattack on a refrigeration equipment provider altered temperature and defrost settings at three facilities, threatening stored blood products Cyberattack disrupts blood storage refrigeration systems in France. The intrusion reached into physical safety controls rather than data, which is the part worth escalating internally.

Binance attributes an approximately $6.34 billion theft to North Korean hackers who used a fake job interview to get an employee to install malware, then compromised wallet infrastructure Binance says fake job interview led to $6.3 billion crypto heist. The transferable detail is the path: recruiting pipeline to engineer endpoint to custody systems.

Crédit Mutuel Arkéa confirmed attackers made transfers using the bank's own accounts after compromising an unnamed supplier, with an estimated $133 million taken French bank confirms cyber heist, hackers suspected to have stolen an estimated $133 million. Third-party access converging with transfer authority, again.

Vulnerabilities

Two Xen flaws let a malicious guest VM read and write the memory of other guests on the same host, including dom0 Xen Hypervisor Flaws Let One Malicious VM Read and Write Any Other VM's Memory. Patches are out, every version from 4.6 onward is affected, and the project says there is no known mitigation; no CVE identifiers appear in the supplied excerpt, so track fixes through the advisory. Hypervisor isolation is the assumption much else rests on.

Ruby on Rails fixed a critical Active Storage flaw that let an unauthenticated attacker write arbitrary files to an app's server via a crafted upload where ImageMagick processes files, with fixes in 8.1.4.1 and 8.0.5.2 Critical Rails Flaw Lets Attackers Write Server Files via Crafted ImageMagick Uploads. Anyone piping user uploads through ImageMagick should treat this as immediate work.

Research

Researchers attribute a large-scale watering-hole campaign to APT29-linked activity, using compromised sites, fake domains and a supply-chain compromise of a Ukrainian web analytics service, with injected JavaScript harvesting browser and device attributes before serving iOS and Android exploits APT29-Linked Hackers Hijack Web Analytics Script to Deliver iOS and Android Exploits. The attribution is theirs and should be read as such; the mechanism — analytics script as delivery vehicle — is the durable lesson.

Industry

Google disrupted the XCPE botnet, saying it had grown to 1.3 million devices — set-top boxes and IoT gear backdoored into criminal infrastructure — and alleges manufacturer Videostrong ran the operation Google, Partners Disrupt 1.3 Million-Device-Strong XCPE Botnet. Consumer IoT defaults keep seeding other people's botnets; accountability for that is the story.
