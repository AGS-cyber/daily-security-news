The latest security picture is defined by active exploitation: two newly catalogued edge-device flaws, a critical WordPress plugin under webshell attack, and an iOS zero-click spyware infection. Breach disclosures add sealed court records and a massive trove of driver’s-license images, while new research shows how Teams impersonation can turn into a hands-on-keyboard intrusion.

Actively exploited

CISA added seven flaws to its Known Exploited Vulnerabilities catalog, and the lead entry is CVE-2026-83548, a pre-authentication server-side request forgery in SonicWall SMA 1000 appliances that carries the maximum CVSS score of 10.0 CISA Adds Seven Exploited Flaws as Attackers Deploy Reverse Shells and Crypto Miners. The bug sits in an unintended alternate access path in the Work Place interface, with NVD associating it with both an alternate-access-path weakness (CWE-441) and the SSRF itself (CWE-918). Because it needs no authentication and can expose sensitive functionality, the KEV listing confirms that real-world attackers are already targeting it. Any organization with an internet-facing SMA 1000 should be treating that appliance as an incident candidate until patch status is verified and compensating controls are in place.

Active exploitation is not limited to items that already have KEV entries. CVE-2026-32475, an unrestricted upload flaw in Elementor Pro, is being used in the wild to plant webshells and execute arbitrary commands on affected WordPress servers Critical Elementor Pro flaw exploited to take over WordPress sites. The vulnerability is patched, but the plugin’s very large installed base means many websites are still running exposed versions. Webshell deployments tend to be followed quickly by backdoor installation and privilege escalation, so site administrators should verify their current plugin version and inspect web roots for unexpected files or suspicious recent uploads even after updating.

Also newly listed in KEV is CVE-2026-9586, an unauthenticated SQL injection in Sangoma Switchvox that attackers are exploiting to deploy reverse shells Hackers exploit Sangoma Switchvox flaw to deploy reverse shells. The vulnerable code processes XML beginning with a phone-platform marker and concatenates a user-controlled IP value directly into a PostgreSQL query. On affected on-premises Switchvox builds from 8.2.2.1 through before 8.4.0.2, a single crafted request can be enough to move from SQL injection to remote code execution. VoIP appliances are easy to overlook on an asset inventory, but this listing is a reminder that conferencing and telephony gear is every bit as reachable as a VPN gateway.

The spyware front also produced a notable confirmation: Citizen Lab and the SHARE Foundation found high-confidence indicators that an iMessage zero-click exploit installed NSO Group’s Pegasus on the iPhone of a member of Serbia’s student protest movement Pegasus Zero-Click Spyware Exploit Infects Serbian Student Movement Member's iPhone. No user interaction was required, which makes this a failure mode that security awareness cannot prevent. For high-risk users, especially journalists, activists, and the organizations supporting them, the practical response is strict device isolation, careful threat modeling, and regular checks for commercial spyware infection indicators.

Breaches

The most legally consequential breach reporting involves Thomson Reuters: a records platform used by courts has exposed sealed court information and sensitive personal data across at least 12 U.S. states, the U.S. Virgin Islands, and Canada US and Canadian court data exposed in Thomson Reuters breach. Sealed filings are not ordinary PII; the harm flows from broken judicial confidentiality, potentially privileged legal content, and exposure of matters that courts deliberately kept out of public view. The fallout will be measured not just in stolen identities but in compromised proceedings, so affected courts and the organizations that rely on the platform need to determine which matters and documents were accessible during the exposure window.

A separate dark-web listing is offering 153 million scans of U.S. and Canadian driver’s licenses, likely stolen from IDScan.net 153 Million Driver License Images Offered on Dark Web. If the data is as described, it represents a mass identity-fraud enabler: license images are used as proof of identity across account opening, employment screening, and financial services, and they can feed document fraud or synthetic identity creation. Identity-verification customers should assume that data submitted through affected systems may now be in criminal hands and should begin watching for signs of misuse.

Vulnerabilities

The WordPress ecosystem also has a high-severity vulnerability with a very large blast radius. CVE-2026-19949 in the All-in-One WP Migration and Backup plugin affects versions through 7.109 and is an SQL injection in the archive-restore functionality Over 3 Million WordPress Sites Affected by Migration Plugin Vulnerability. The injection allows an attacker to append SQL to an existing query and extract the site’s ai1wm_secret_key; when an administrator later performs an archive restore, that key can be leveraged to achieve remote code execution. With more than three million sites using the plugin, administrators need to update immediately and audit recent restore activity for signs that the flaw was already abused.

Research

Threat intelligence from Microsoft describes a human-operated campaign that abuses Teams external collaboration to impersonate IT support Impersonating IT support: how threat actors turn a remote session into enterprise-wide access. The attacker uses that trusted identity to convince a target into a remote session, then relies on legitimate tooling for lateral movement before deploying a Node.js-based implant. The campaign matters because it bypasses defenses built around email phishing: the initial contact arrives through a collaboration platform and invokes the name of the victim’s own support team. Defenders should treat unsolicited external Teams requests from anyone claiming to be IT as high risk, enforce explicit approval for external meetings, and watch for remote-control utilities being launched from otherwise legitimate user sessions.
