Vulnerabilities

The top priority is a cluster of critical flaws in WordPress plugins and themes that can lead to authentication bypass, account takeover, and arbitrary code execution Five Critical WordPress Plugin and Theme Flaws Enable Site Takeover or RCE. The most dangerous is an authentication bypass in WPMU DEV Dashboard, tracked as CVE-2026-76581 with a CVSS score of 9.8. Affecting versions up to and including 5.0.1, the flaw stems from inconsistent HMAC message construction between two unauthenticated AJAX actions; an attacker can obtain a valid signature from one step and replay it into another, swapping the domain into the redirect field to get an authenticated administrator session. The underlying weakness is a cryptographic signature verification problem, and the unauthenticated nature of the attack is what makes it so dangerous: no credential or previous access is required.

The same disclosure round covers critical flaws in Avada, TranslatePress, Pods, and GiveWP. Specific details vary, but the collective risk is site takeover: an attacker who compromises any one of these components can typically move from code execution to server-level compromise. For WordPress administrators, the immediate action is to update all five components as soon as patches are available. The presence of a critical, network-exploitable authentication bypass should be enough to move this to emergency change management rather than the normal maintenance window.

Breaches

A threat actor claiming responsibility for a Manchester Airports Group incident says it stole 86 GB of data, and at least one record in the sample has been validated as a real traveller's record FulcrumSec claims Manchester Airports hack, theft of 86 GB of data. That sample reportedly includes detailed customer, booking, and travel information, going beyond what the airport operator initially acknowledged. The validated record matters because it shifts the question from whether the breach is real to whether the disclosure is complete.

For anyone affected or responsible for similar travel-related data, the immediate concerns are the usual ones: the data set is likely to appear in follow-on phishing and targeted social engineering, and any exposed booking or itinerary details can be used to make fraudulent confirmation messages more convincing. The larger lesson is about incident communication: if an attacker's sample contains more precise fields than the formal disclosure, the organisation should expect those details to be weighed against the official narrative.

Actively exploited

Anthropic is warning that infostealer malware on users' PCs has been stealing active Claude login sessions, giving attackers access to accounts and letting them drain usage Anthropic warns infostealer malware is hijacking Claude sessions to drain usage. This is a reminder that session tokens are now a first-class theft target: an infostealer can lift an authenticated session and bypass many of the friction controls that protect the login flow. Enabling multi-factor authentication is still worthwhile, but its value is limited if the stolen session remains valid. Users should also scan machines for infostealers, especially if they see signs of unusual usage on a Claude account.

A separate campaign hit browsers directly: malicious extensions for Google Chrome and Microsoft Edge deployed a modular malware framework that stole cryptocurrency, browser data, and browser history, and in some cases injected ClickFix lures Chrome Web Store extensions caught stealing crypto, browser data. The extension framework is notable because browser extensions sit inside the security boundary of the browser: they can read active site contexts, redirect transactions, and persist long after a credential rotation. Anyone who discovers an unauthorized extension should remove it immediately and rotate credentials from a clean device. The overlap with the ClickFix lure is also worth tying together: attackers are converging on the same social-engineering pattern across extensions, AI assistants, and terminal commands.

Research

Microsoft has documented a new ClickFix variant called TerminalFix that uses fake Cloudflare CAPTCHAs to push users toward Windows Terminal or PowerShell TerminalFix Uses Fake Cloudflare CAPTCHAs to Deploy Reverse-Tunnel Backdoor. Traditional ClickFix campaigns direct victims to the Windows Run dialog; TerminalFix instead asks users to paste commands into a full terminal window, where complex payloads are less likely to be questioned. The end result is a reverse-tunnel backdoor that gives the attacker remote access to the machine.

The shift from Run to Terminal is significant for defenders because it changes the tell users have been trained to spot. A CAPTCHA that asks the user to open Windows Terminal or PowerShell is always suspicious, and the appearance of a powershell or curl command under the guise of human verification should be a hard stop. For security teams, this is another reason to restrict script execution where possible and to make sure users know that no legitimate CAPTCHA will ever ask them to run a command.
