Actively exploited flaws in Check Point gateways and N-able N-central lead the day, while PostgreSQL’s latest update fixes an authenticated code-execution bug. Police disruption, GitHub account abuse, DPRK crypto theft and telecom interception round out the picture.

Actively exploited

Check Point gateways are the lead story: PHP2Shell was used for initial compromise, while CVE-2026-123039 let attackers elevate to root in destructive attacks PHP2Shell Exploited in Destructive Check Point Gateway Attacks. The flaw is a High-severity 7.8 permission-assignment issue in which the Gaia OS DynamicCLI daemon listens on a world-writable local socket without authenticating connecting processes; an authenticated local user can have commands executed as root. CISA lists it in KEV and sets a federal remediation deadline, which raises urgency but does not create a universal one. The local, authenticated precondition matters: this is not a remote unauthenticated path.

N-able’s N-central zero-day, dubbed 4EverAble2Shell, was exploited within hours of a PoC release to compromise servers and deploy cryptocurrency miners, with researchers reporting at least 21 affected systems, including 19 running the latest security update New N-able "4EverAble2Shell" zero-day exploited hours after PoC released. No CVE was supplied. Analysis: that concentration on current builds makes patch-bypass risk the immediate question for MSPs, though the excerpt does not explain the mechanism.

Vulnerabilities

PostgreSQL’s latest release fixes 52 flaws, including CVE-2026-6460, a 22-year-old type-confusion bug that lets a database user who can create objects execute code as the OS user running the database PostgreSQL Patches 52 Flaws, Including 22-Year-Old Bug Enabling Authenticated RCE. It is High severity at 8.8 with a network vector but low privileges required, and NVD lists versions before 18.7, 17.12, 16.16, 15.20 and 14.25 as affected. Full protection also requires rebuilding C-language extensions. No KEV entry was supplied. Separately, Nightmare Eclipse released a Windows zero-day exploit called SignDrop that abuses CLFS and Windows Defender to trigger arbitrary file creation in the context of the antimalware process Nightmare Eclipse Drops Windows Zero-Day Exploit ‘SignDrop’. No CVE, affected versions or patch status were supplied. The significance is the attack path itself: a Defender-context file write is a primitive defenders should track, but the excerpt does not establish in-the-wild exploitation.

Industry

Operation Endgame took down servers behind Gootloader, CastleRAT and StealC, and police seized about 6.4 million stolen logins belonging to more than 40,000 victims, according to Germany’s BKA Operation Endgame Takes Down Gootloader, CastleRAT and StealC Servers, Seizes 6.4M Stolen Logins. The tools were used for access, password theft and ransomware, so the disruption targets infrastructure that feeds criminal access and extortion.

Breaches

The wfx-loot campaign used 4,837 compromised GitHub accounts to probe 61,764 repositories, open pull requests and push secrets-stealing malware Hackers compromise 4,800 GitHub accounts to steal cloud credentials. The scale is the story: cloud credentials are the prize, and repository write access is the delivery mechanism. Analysis: that combination is a supply-chain risk for organizations whose code depends on GitHub, though the excerpt does not name victims or estimate credential loss. The FBI attributes more than $400 million in cryptocurrency theft to DPRK-tied actors running a social-engineering scheme codenamed FaceStealer, using deepfake video calls FBI Says North Korean Hackers Stole Over $400 Million in Crypto Using Deepfake Video Calls. The alleged campaign ran over an 18-month span and is part of a coordinated set of U.S. government actions. The attribution is the FBI’s, not an independent assessment in the excerpt. Analysis: the case reinforces that deepfake-assisted social engineering can convert trust into direct financial loss, but no technical indicators were supplied.

Research

Enea named SilentAir, a spying group it assesses with high confidence to be state-level, after finding attack sources inside mobile operators in at least six Asian countries SilentAir Hijacks Asian Telecom Networks to Intercept SMS 2FA Codes and Spy on Taiwanese Users. The group used hacked equipment to intercept calls and texts, including SMS 2FA codes, for selected people, mostly in Taiwan. Analysis: operator-level interception is a direct challenge to SMS-based second factors for targeted users, though the excerpt does not detail how targets were selected.
