The day's agenda is set by vendors shipping emergency fixes for flaws attackers already have working. Check Point and F5 both pushed hotfixes for KEV-listed bugs in exactly the kind of infrastructure that sits in front of everything else, a Chinese actor is running a full browser-to-kernel chain against Chrome and Windows, and Arista is patching a VeloCloud Orchestrator zero-day. Ubuntu still has not shipped the upstream fix for a container escape with public exploit code, cPanel handed any hosting tenant a path to root, and ShinyHunters claims it reached FBI systems through PeopleSoft. Microsoft, meanwhile, has dismantled a phishing-as-a-service operation behind roughly 12,000 inbox compromises.

Actively exploited

The lead is Check Point's Management Server. CVE-2026-93616 is a path-traversal and file-upload flaw in the CWE-22 family that lets an unauthenticated attacker upload and execute arbitrary scripts on the management server itself — CVSS 9.8, and reachable over the network with no privileges and no user interaction. It is in CISA's catalog, which means exploitation is confirmed rather than theorised, and the required action is to apply mitigations per vendor instructions under federal patch guidance, with a remediation deadline only days out for federal agencies. That deadline is not a universal one, but the practical reading is the same for everyone: hotfix Check Point warns of Management Server zero-day exploited in attacks now, and check for the uploaded scripts afterward, because the exploitation window predates the fix.

F5 has the same shape of problem in BIG-IP APM. CVE-2026-94127 is a heap-based buffer overflow (CWE-122) that yields unauthenticated remote code execution when an APM access policy and an OAuth profile are configured on a virtual server — CVSS 4.0 base of 9.3, and present in Appliance mode too. The configuration caveat matters and cuts both ways: APM used strictly as an OAuth client or resource server is not affected, which should shrink the panic list, but that list is precisely the identity infrastructure nobody wants to take offline. Affected ranges include 17.0.0 through 17.1.3, 17.5.0 through 17.5.1, and 21.1.0. It is KEV-listed as exploited, and this is a data-plane issue with no control-plane exposure, so your internet-facing APM virtual servers are the ones to inventory first F5 Patches Critical BIG-IP APM Zero-Day Exploited for Unauthenticated RCE on OAuth Servers.

The most interesting attack of the day is the exploit chain attributed to a Chinese actor tracked as UTA0565. It strings together three separately KEV-listed bugs: two Chrome V8 flaws, a type confusion (CWE-843, CVSS 8.8) and an out-of-bounds write (CWE-787, CVSS 8.8), both reachable from a crafted HTML page inside the sandbox, then a Windows ALPC heap-based buffer overflow (CWE-122) rated 7.8 that elevates privileges locally. Delivered through fake websites and observed being used as zero-days, the chain ends in CLEANGULP malware. Two of the three bugs are already past their federal remediation deadlines, which tells you how quickly this campaign moved from disclosure to weaponisation Chinese Hackers Exploit Chrome-Windows Zero-Day Chain to Deploy CLEANGULP Malware.

Less metadata, same urgency: Arista has released patches for a VeloCloud Orchestrator zero-day that is being actively exploited, affecting on-prem VCO deployments. No CVE identifier or scoring was included in what we have, so treat the operator guidance as the authority — if you run VCO On-Prem, this is an immediate action item rather than a scheduled one Arista patches actively exploited VeloCloud Orchestrator zero-day.

Breaches

ShinyHunters says it breached FBI systems by way of a new Oracle PeopleSoft zero-day, reaching internal services and exfiltrating data on employees and job applicants, and is threatening to leak it. Nothing here is confirmed by the bureau, and extortion gangs routinely overstate what they hold — but PeopleSoft sits in HR and applicant-tracking estates at large organisations everywhere, so the interesting question is not whether the claim is accurate. It is whether your PeopleSoft exposure matches the one being described, and whether a zero-day that never reaches a vendor advisory is now your problem ShinyHunters claims FBI hack, data theft in PeopleSoft zero-day breach.

Vulnerabilities

A public exploit now exists for CVE-2026-80521, a use-after-free in the Linux kernel's AF_UNIX socket subsystem that escapes a container and lands root on the host. It carries a CVSS of 7.8 and was fixed upstream in the kernel, but Ubuntu has not shipped that fix for its 26.04, 24.04, or 22.04 LTS releases — so the distro packages many of you are actually running remain exposed to working exploit code. KEV does not list it, and absence from that catalog proves nothing either way; the operative fact is a public exploit plus an unpatched distribution Exploit Released for Unpatched Ubuntu Linux Flaw Enabling Host-Root Container Escape.

cPanel's pair of bugs deserve attention from anyone renting or reselling shared hosting. A flaw in its CalDAV and CardDAV service lets anyone holding a cPanel account execute code as root and take full control of the server, which turns tenant isolation into a fiction. A second bug in the WP Toolkit plugin lets an account holder modify databases belonging to other accounts — quieter, but the same boundary failure. Fixed versions are out for both; the risk concentrates in providers who patch on their own leisurely schedule rather than their customers' New cPanel Flaw Lets a Hosting Account Run Code as Root, Take Full Server Control.

Industry

Microsoft has taken down EvilTokens, a device-code phishing service tied to roughly 12,000 inbox compromises, acting under court authorisation with support from Health-ISAC and a set of technology and threat-intelligence partners. The detail worth internalising is the operational one: device-code phishing abuses a legitimate OAuth flow, so there is no malware to detect and no patch to apply — only conditional-access policy, sign-in log review, and a hard look at which applications in your tenant still permit device-code authentication Microsoft Takes Down EvilTokens Device-Code Phishing Service Tied to 12,000 Inbox Compromises.
