Actively exploited

The day’s most urgent story is the StyleSmuggler zero-day in Adobe Commerce and Magento Open Source Adobe Patches Magento Zero-Day Exploited to Deploy Rust Backdoor and PHP Web Shell. Tracked as CVE-2026-75650 with a CVSS score of 10.0, the flaw is a template-engine injection issue that lets an unauthenticated attacker execute code in the context of the current user, with no user interaction required and a changed security scope. Sansec identified active exploitation before Adobe shipped a patch. The observed post-exploitation activity is what makes this stand out: attackers are dropping Rust-based backdoors and PHP web shells on online stores, a pattern that points to long-term access rather than a quick data grab. E-commerce platforms are a high-value target precisely because a single compromised storefront can feed fraud, credential phishing, and supply-chain abuse for months. The CVSS profile matches the real-world tradecraft: no authentication, no user click, and an easy path from template injection to arbitrary code.

Breaches

An exposed advance passenger information system linked to Vietnam shows what default credentials still cost 220 million traveler records exposed in Vietnam-linked APIS leak. The database held 220 million passenger and crew records, including names, passport numbers, nationalities, dates of birth, and flight histories spanning nearly a decade. Researchers reached the system through a cloud-facing path protected by default credentials. The sheer volume matters less than the data type: passport numbers and travel patterns are durable identity assets, the kind of records that enable targeted fraud, border-hopping attempts, and social engineering long after the exposure is closed. Traveler databases also tend to cross borders and jurisdictions, which complicates notification and remediation. A system holding this much identity data should never have been one default login away from the internet.

The Liquid Network incident remains unresolved despite a surprising partial return Liquid Hackers Return 3,400 Bitcoin Taken via Elements Bug, Still Holding $47M in BTC. Whoever exploited an Elements bug to steal nearly 4,000 bitcoin sent back 3,400 of it the following day, leaving roughly 598.5 bitcoin, worth about $47 million, unreturned. Liquid is still paused, meaning holders cannot convert their L-BTC tokens back into real bitcoin. The pause protects users from further losses but also locks in collateral damage by freezing legitimate redemptions. Partial returns are difficult to interpret: they could reflect a ransom negotiation, a failed laundering attempt, or an attacker minimizing exposure. The remaining balance and the continued network freeze mean the underlying sidechain code has not yet been cleared for normal operation. For anyone relying on Bitcoin sidechains, this is a reminder that the security of the pegged asset depends on the correctness of the sidechain software, not just the integrity of the main chain.

Vulnerabilities

FreeIPA is the trust anchor for many Linux domains, so a flaw chain that lets anonymous clients mint administrator credentials is about as bad as it gets FreeIPA Flaw Chain Lets Anonymous Clients Create Reusable Administrator Credentials. Red Hat warns that a client that has never logged in can create a Kerberos identity of its own choosing, end up in the administrators group, and produce reusable admin credentials. The attack depends on a second flaw in the 389 Directory Server software underlying FreeIPA’s LDAP store. The result is a complete collapse of domain trust: the attacker starts with no authenticated foothold and finishes with credentials that look legitimate and remain valid. Response cannot stop at patching the two flaws; administrators need to audit existing identities for unexpected administrators and rotate credentials that may have been minted through the chain.

SAP’s latest batch of updates covers 20 vulnerabilities, and the one that deserves attention is OVERPASS, a maximum-severity memory corruption issue in the SAP Kernel SAP warns of maximum severity 'OVERPASS' kernel vulnerability. The flaw gives remote attackers both code execution and the ability to recover secrets. Kernel-level access in an SAP environment is not a single-system problem; SAP systems are usually the backbone of finance, logistics, and identity processes in large enterprises, so remote kernel compromise can quickly become enterprise-wide data exposure or fraud enablement.

A proof-of-concept from security firm Calif shows a WeChat worm that takes over accounts through an incoming call on both iPhone and Android WeChat Zero-Click Worm Took Over Accounts on iPhone and Android via Incoming Calls. The receiving user does not need to answer or touch the phone, but the caller must already be one of the target’s contacts. That contact requirement is real but not limiting: a worm that compromises one account inherits that account’s contact list and can use it to reach the next victim. Calif demonstrated propagation across three test phones. The attack has not been described as in-the-wild exploitation, but it is an unusually clean example of a zero-click messaging flaw with worm potential, and Tencent has been notified.

The N-able N-central zero-day patch is notable for what the vendor told administrators to do after updating N-able Patches Critical Zero-Day in N-central. Deployment guidance is to check for unrecognized administrator accounts. N-central is a remote monitoring and management platform, so a malicious administrator account inside it is not just a tenant issue; it can become a route into every managed endpoint. The warning suggests the zero-day may have been used to establish persistence before the patch existed, and that a console-level account hunt should be part of the remediation process.

Research

Google’s threat intelligence group is now documenting autonomous AI attacks as an operational reality rather than a demo Autonomous AI Agents Compromise Thousands of Credentials in Under Six Hours. One financially motivated group used a multi-agent framework to harvest thousands of credentials in under six hours, and Google observes attackers with diverse motivations targeting proprietary AI systems. The scale and speed are new: this is not an AI generating a phishing email while a human does the rest. The full loop of reconnaissance, credential access, and payload delivery appears to have been delegated to coordinated agents. For defenders, the implication is that attack tempo—and the cost of experimentation—has shifted. Security teams need to assume that credential harvesting can now happen at machine speed, and that a single misconfiguration can be discovered and exploited in hours rather than days.
