Today’s briefing is about two forces at once: sheer volume and sharp certainty. Microsoft broke its own record, SAP pushed out another maximum-severity fix, and Chrome, N-able, and Adobe all have exploited bugs to act on. Behind the CVEs sit warnings on AI-model extraction, a memory-resident rootkit on F5 appliances, and stolen AI sessions that outlive password resets.

Vulnerabilities

Start with the number in Microsoft Patches Record 974 Vulnerabilities, Including Two Exploited Zero-Days: 974 vulnerabilities, two privilege-escalation zero-days already exploited in the wild, and 20 bugs Microsoft considers potentially wormable. The record count is less important than how it changes triage. A release this large guarantees that not every CVE deserves the same response. The exploited pair should be treated as emergency changes, the wormable set should be matched against internet-facing assets, and the remainder should be prioritized by reachability and business impact. If your process still cannot handle a four-digit month, that is an automation problem the patch volume just made visible.

SAP Patches CVSS 10.0 Kernel Flaw Enabling Unauthenticated Remote Code Execution shows why prioritization cannot be purely CVE-count based. SAP fixed a 10.0-rated memory corruption flaw in Extended Passport processing that allows an unauthenticated attacker to send a malformed EPP header in a crafted network request, with potential impact to confidentiality, integrity, and availability. There is no public exploitation report and no KEV listing, but an unauthenticated parser bug in an enterprise suite still needs a deliberate answer: identify every exposed SAP system, verify whether the vulnerable component is reachable, and patch before the public exploit matures.

Actively exploited

The browser is the shortest path from user action to code execution, and Chrome V8 Zero-Day Exploited in the Wild Enables Code Execution Inside Sandbox is a good example. Chrome’s V8 engine has an out-of-bounds write, CVE-2026-87491, fixed in version 153.0.8010.36, and already exploited in the wild. A crafted web page can run code inside the browser sandbox, so this is not a network-exposure bug; it is a user-click bug, and the fix must be pushed rather than requested. The CVE is absent from CISA’s KEV catalog, but vendor-confirmed in-the-wild exploitation is a stronger signal than catalog membership.

For platforms that sit one hop away from the network, the KEV list is carrying the weight. N-able N-central Pre-Auth RCE Flaw Exploited in the Wild covers CVE-2026-86218, a pre-authentication remote code execution in N-able N-central rated 10.0 under CVSS v4.0 and affecting versions before 2026.3.1.14; CISA has confirmed exploitation by adding it to KEV. An RCE in a remote monitoring platform is a privileged pivot point, because the tool is trusted with managed endpoints. Adobe Patches Over 170 Vulnerabilities, Including Commerce Zero-Day is the e-commerce equivalent: CVE-2026-75650 in Adobe Commerce and Magento is a template-engine injection that lets an unauthenticated attacker execute code without user interaction. Adobe patched more than 170 issues this cycle, but the Commerce flaw is the one on KEV. Its affected configuration includes releases before 2.4.4 and the 2.4.4 line through p18, so knowing which build you have is a matter of urgency, not convenience.

Industry

China-Based Artificial Intelligence Companies Conducting Industrial-Scale Distillation Campaigns Against U.S. AI Companies is the reminder that not every urgent story arrives as a CVE or a patch. U.S. agencies have assessed that China-based AI companies are running industrial-scale knowledge distillation against American frontier models, treating extraction of proprietary model capabilities as the core of their development strategy rather than an opportunistic shortcut. Distillation is a legitimate technique, which is exactly why this is hard to police at the network boundary. AI providers and enterprises with valuable models should look for bulk querying, repeated sampling patterns, and telltale request sequences that suggest someone is reconstructing behavior. Model functionality now belongs on the short list of assets that require monitoring, access controls, and incident-response planning.

Breaches

Hackers breach F5 BIG-IP APM devices to deploy Linux rootkit adds a fileless twist to appliance security. Attackers have breached F5 BIG-IP APM environments with a Linux rootkit that intercepts PHP file loading and injects a web shell directly into memory, never writing the payload to disk. Disk-based scanning and file integrity monitoring will miss the active phase of this attack. Defenders hunting on BIG-IP should be checking for hooked PHP file-load operations and memory-resident shells, and should treat a clean filesystem as an incomplete forensic answer.

Research

Finally, Infostealer Logs Expose Replayable AI Tokens That Can Bypass MFA warns that AI accounts are now a first-class infostealer target. Logs from Lumma Stealer, Vidar, and similar malware expose session tokens and API keys for AI providers including Google and Anthropic. Those tokens are bearer credentials: they stay replayable even if the user resets a password or re-enrolls MFA, so authentication alone does not protect the account. The practical response is to rotate API keys, shorten session lifetimes, bind sessions to devices or risk signals, and monitor AI usage for anomalies as seriously as you would monitor a stolen cloud key.
