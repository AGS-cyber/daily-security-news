Vulnerabilities

Docker Hub carried a critical incorrect-privilege-assignment flaw, CVE-2026-105445, rated 9.4 under CVSS 4.0 Docker Hub flaw let attackers impersonate users, tamper with images. Per the structured record, an authenticated attacker could reassign a personal access token they controlled to another Docker Hub user without rotating or revoking the token secret; the unchanged token then authenticated to the registry as the recipient and could pull, push or delete images within its scopes, including organization repositories. There is no indication in the supplied intelligence that it was exploited.

GitLab patched a CVSS 10.0 issue that, under certain conditions, could have allowed an unauthenticated user to execute arbitrary code on the server via a specially crafted regular expression in CI/CD, affecting Community and Enterprise Editions GitLab Patches CVSS 10.0 Flaw That Could Let Unauthenticated Users Run Server Code. No CVE ID was supplied. Self-hosted instances are the relevant exposure.
