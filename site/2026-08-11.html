Ransomware finds new doors into networks while trust chains crack

8 of 48 stories written up · 12 of 12 sources · generated 12:52 UTC

Ransomware groups are now exploiting Microsoft SharePoint and SonicWall SMA1000 flaws, and an unnamed Metabase zero-day is under active attack. Elsewhere, a Polish power plant was hit through a private cellular network, a WordPress plugin vendor was compromised through poisoned JSON, and new Windows research shows a USB attack surface that also works over RDP.

Actively exploited

CISA has confirmed that ransomware gangs are abusing a high-severity Microsoft SharePoint remote code execution flaw that was already flagged as actively exploited CISA: Microsoft SharePoint flaw now exploited in ransomware attacks. The practical takeaway is that unpatched on-premises SharePoint servers are no longer just a data-exposure risk; they are a viable beachhead for encryption and extortion. Patch on-prem servers immediately and treat any already compromised host as a full domain compromise until proven otherwise.

CISA has also confirmed ransomware exploitation of two recently patched SonicWall SMA1000 vulnerabilities, including a maximum-severity SSRF flaw and an authentication-bypass issue CISA: SonicWall SMA1000 flaws now exploited by ransomware gangs. The combination is dangerous: an SSRF can let an attacker reach internal services through the appliance, and an auth bypass can turn a network position into administrative access. If SMA1000 appliances have not been updated, they should be treated as exposed and upgraded without waiting for a scheduled maintenance window.

The third actively exploited story is a reminder that zero-days do not need a CVE to be dangerous. A maximum-severity Metabase SQL flaw is under active attack even though no CVE has been assigned, allowing remote administrative access to the business-analytics platform and everything downstream of it Metabase SQL Zero-Day Attacks Could Have Wide Blast Radius. Because there is no identifier to track, defenders cannot rely on CVE feeds to spot affected versions; they need to inventory every exposed Metabase instance and assume any reachable deployment is compromised. Reducing the blast radius means removing public exposure, enforcing authentication, and checking for rogue admin accounts or suspicious database queries.

Industry

Ransomware-as-a-service continues to industrialize. U.S. and South Korean authorities warn that Gunra, a RaaS variant that began as a standalone ransomware and later expanded to affiliates, is breaching government, critical infrastructure, and other organizations through firewall flaws #StopRansomware: Gunra Ransomware. Gunra affiliates run a double-extortion playbook, and the advisory highlights the pattern of exploiting perimeter vulnerabilities for initial access. The signal for defenders is that firewall appliances are themselves an initial-access vector; patch and harden perimeter devices, and assume affiliates will reuse those footholds against similar targets.

Key management failures are also an industry-level story. Mozilla revoked the Linux signing key for Firefox and Thunderbird after an unencrypted copy was accidentally committed to one of its own private repositories Mozilla Revokes Firefox and Thunderbird Linux Signing Key After Key Lands in Private Repo. That key is the trust anchor for verifying that downloaded tarballs came from Mozilla and were not tampered with. The revocation is the correct call, but it has a cost: Linux distributions that package the browsers must rotate to the new key, and users may need to verify the new signing material before upgrading. The incident is a useful reminder that a signing key is only as valuable as the controls around its storage and export.

Breaches

OT security often fails at the convergence of IT and operational networks. In Poland, attackers breached a combined heat and power plant by coming in over the private cellular network the local grid operator uses to reach remote equipment, then shut down a steam turbine and the process-water treatment system Hackers Breach Polish Power Plant Controls via Private Cellular Network and Shut Turbine. The plant supplies heat to roughly 50,000 residents, and recovery began while the intruders were still active inside the network. Customers lost neither heat nor power, but the incident demonstrates that cellular APNs and other remote-management links are now in the crosshairs of attackers targeting OT. Segment those links, monitor for lateral movement, and treat the carrier network as an untrusted boundary.

Supply chain compromise is not always about modified source code. An attack against WordPress plugin vendor BdThemes used poisoned JSON to create rogue WordPress admins, and the WordPress plugins team temporarily disabled the vendor's downloads BdThemes Supply Chain Attack Poisons JSON to Create Rogue WordPress Admins. Notably, researchers found no source code files were modified within the official WordPress.org repository, making this a subtler form of tampering that can evade code-review and integrity checks. Any site running BdThemes plugins should audit for rogue administrator accounts, review plugin updates with suspicion, and consider the plugins compromised until the vendor demonstrates a clean rebuild.

Research

Windows research continues to find privilege-escalation paths in surprising places. Researchers demonstrated that Windows Plug and Play can be abused to fetch signed vendor software for an emulated USB device, then execute privileged installation components to gain SYSTEM access on a fully updated Windows 11 machine Researchers Turn USB Auto-Install Into a Full SYSTEM Takeover on Windows 11. The attack also works over Remote Desktop without physical hardware when supported Plug and Play or low-level USB redirection is enabled, meaning a remote attacker with code execution in a user session can turn a legitimate PnP trust chain into a full system takeover. For defenders, the practical mitigation is to disable USB redirection and PnP passthrough in RDP policies, restrict device installation rights, and monitor for unexpected PnP device arrivals or driver installs.
