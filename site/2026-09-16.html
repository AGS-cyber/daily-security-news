Today's active-exploitation stories share one shape: a reachable component, a logic error rather than a memory-safety bug, and little or no authentication in the way. Two others describe the same failure one layer up the stack — a hijacked AI coding assistant and a poisoned plugin update — which is where the leverage now sits.

Actively exploited

Start with Google Patches Pixel Modem Flaw Amid Signs of Limited Targeted Exploitation. Google's Pixel cellular modem has a permission bypass — a logic error, not memory corruption — tracked as CVE-2026-58704 and scored 8.0. The vector matters more than the number: proximal/adjacent attack, low privileges required, no user interaction, and high confidentiality, integrity and availability impact. Anything within radio range can drive it, so "don't click the link" is not a mitigation. Google has confirmed targeted exploitation, and the flaw now sits in CISA's KEV catalog with a federal remediation deadline attached. Pixel owners have no reason to wait.

Critical ScreenConnect flaw now actively exploited in attacks applies the same urgency to remote-support infrastructure. CISA says attackers are actively exploiting a critical flaw in ConnectWise ScreenConnect, which is precisely the software you should never assume is safe: it is a remote-control channel by design, reachable from the internet, and a foothold there becomes an interactive session on someone else's endpoint. Internet-exposed ScreenConnect servers are an immediate takeover risk and belong at the front of the queue — patched, or taken off the internet entirely.

Active Exploitation Attempts Target WSO2 API Manager JWT Bypass With Forged Admin Tokens is the most underrated of the four. CVE-2026-5430 is a JWT verification failure in WSO2 API Manager — improper verification of a cryptographic signature, CWE-347 — where the gateway accepts tokens signed with algorithms it should reject. The result is unauthenticated account takeover, up to and including administrative accounts, and forged admin tokens are already being thrown at exposed instances. The scoring is instructive: 9.8 as adjusted by the vendor for single-tenant deployments, a full 10.0 under NVD's default scope metric. The affected surface is broad — API Manager across the 4.1.0 through 4.6.0 lines below specific build numbers, plus API Control Plane, Traffic Manager and Universal Gateway. It is not in KEV, which is a confirmed catalog miss and nothing more; exploitation attempts are reported regardless. Forged tokens are visible in gateway logs, so hunt before assuming your patch landed in time.

Then Attackers Exploit WooCommerce Wholesale Lead Capture Flaw to Plant PHP Web Shells, where attackers are chaining an unauthenticated file-upload flaw in WooCommerce Wholesale Lead Capture into PHP web shells and remote code execution. The plugin has more than 6,000 active installs. Detection tooling has already been busy blocking it, so the exploit is not theoretical. If the plugin is present, treat the site as compromised until you have looked for dropped PHP and unexpected admin accounts.

Research

Attacker Hijacks AI Coding Assistant Session, Spreads Shai-Hulud Across About 100 Repositories should change how you think about developer tooling. An attacker hijacked a live AI coding-assistant session at a software-as-a-service provider, got the assistant to recommend software the attacker had poisoned, watched the recommendation get accepted, and then rode the Shai-Hulud worm across roughly 100 internal repositories, taking repository secrets and source code with it. The worm is the payload; the interesting part is that the assistant sat inside the trust boundary and turned a hijacked session into a poisoned dependency recommendation. If your developers take package advice from a model, that session is a supply-chain control, and its transcripts are an audit log worth reading.

Breaches

Malcious Admin Menu Editor Pro plugin backdoors 1,500 WordPress sites is the smaller-blast-radius version of the same lesson. Malicious versions of the Admin Menu Editor Pro plugin for WordPress were pushed out after the maintainer's site was compromised, creating a hidden user account on affected installations. Reports put the reach at more than 200 customers and roughly 1,500 sites — modest next to a commercial vendor compromise, but the mechanism costs an attacker almost nothing, and a hidden admin account is exactly the persistence that survives a plugin rollback. Audit your plugin administrators, not just your plugins.

Vulnerabilities

Chrome, Firefox Updates Patch 115 Vulnerabilities is the routine that keeps being non-optional: 42 fixes in Chrome and 73 in Firefox, 115 defects in one cycle. Nothing here is described as under exploitation, and the volume is ordinary — which is the point. Browser patches are cheap insurance against the one flaw in the batch that completes somebody's exploit chain.

Industry

Finally, EU chief wants joint response to cyberattacks, sabotage: the European Commission's annual address to parliament called for a joint response to cyberattacks and sabotage, pointing to recent incidents in Denmark, Lithuania and Poland and an attempted drone attack in Leipzig. The framing — threats "mounting on our soil" — signals that bloc-level incident response and attribution are moving from aspiration toward programme. Nothing to patch yet, but it is the kind of language that later becomes compliance obligations.
