Actively exploited

If you run Sangoma Switchvox, start here. CVE-2026-9586 is a critical, unauthenticated SQL injection in the /pa endpoint that can execute arbitrary SQL against the backend PostgreSQL database, including operations that lead to code execution Sangoma Switchvox Vulnerabilities Exploited in the Wild. CISA has confirmed exploitation in the wild and added the flaw to its Known Exploited Vulnerabilities catalog. The affected on-premises range begins at 8.2.2.1 and ends before 8.4.0.2, and the catalog entry puts federal agencies on a fast BOD 26-04 remediation clock. For everyone else, the KEV listing is a signal to treat exposed Switchvox systems as an emergency patch rather than routine maintenance.

Citrix NetScaler is not in the KEV catalog yet, but it is in the same urgency class. CVE-2026-19490 is a critical authentication bypass affecting NetScaler ADC and Gateway, and it is already being leveraged in attacks Critical Citrix NetScaler auth bypass now leveraged in attacks. Because these appliances sit at the network boundary, an authentication bypass is often a foothold for further compromise rather than an isolated device issue. If you have not updated the affected 14.1 or 13.1 lines, treat any internet-facing NetScaler as potentially exposed. The absence of a KEV entry should not be read as reassurance: observed attacks are still the more authoritative signal.

Browser teams should push out the Chrome update immediately. CVE-2026-85046 is a type confusion bug in the V8 JavaScript engine, and a crafted HTML page can execute code inside the sandbox on versions prior to 152.0.7977.82 Google Releases Chrome Update to Patch Actively Exploited V8 Zero-Day. The fix is already in a stable release, but exploitation is active enough that waiting for users to restart their browsers is the wrong approach. Enterprise patch tools should treat this as a forced update, not an optional prompt.

WordPress operators face a volume problem rather than a subtle one. More than 440,000 exploit attempts have been observed against two plugin flaws: a critical arbitrary file upload in Super Forms and a companion RCE issue in Elementor Pro Over 440,000 Exploit Attempts Target Super Forms and Elementor Pro RCE Flaws. For CVE-2026-14894, the route is especially cheap. Missing file type validation and absent capability checks on an AJAX handler let an unauthenticated attacker mint a valid nonce in one request and upload an executable file in a second. Every affected Super Forms version through 6.3.313 is exposed. With that many attempts in the wild, vulnerable sites are being found by scanners, not by luck.

Vulnerabilities

Cisco’s Nexus 9000 advisory is notable because it combines no authentication, remote access, and root-level impact. CVE-2026-20212 affects ten Silicon One-based Nexus 9000 switches and exists because TCP ports 43210 and 43211 are reachable in the default Layer 3 VRF Critical Cisco Nexus 9000 Flaw Lets Unauthenticated Remote Attackers Run Code as Root. An attacker who can connect to those ports can send crafted input that executes with root privileges, and the same input can crash the S1HAL process and reload the device. Cisco has issued patches for the affected platforms, along with an IOS XR hardening release bundling seven umbrella CVEs, two of them rated 9.8. The lack of a workaround for any IOS XR version makes change windows painful, but leaving an unauthenticated root-level exploit exposed on network infrastructure is a bigger risk than a brief maintenance outage.

PostgreSQL administrators should look at CVE-2026-6471 even though it has been sitting in the codebase for twelve years. Dubbed PostGREShell, the bug turns a non-superuser account that holds the REPLICATION privilege into code execution as the operating system account running the server 12-Year-Old PostgreSQL Vulnerability Enables Database, Server Takeover. The issue is missing authorization during logical decoding: the attacker can choose a decoding plugin that causes PostgreSQL to load an arbitrary shared library. That leads to arbitrary code execution, and the researchers describe a path to permanent superuser privileges and a persistent backdoor. Replication privileges are often treated as low-risk because they are not superuser, but this vulnerability shows how much trust that role actually carries. The fix is to upgrade to a patched release in a supported PostgreSQL branch.

The wildcard in this section is CrowdStrike Falcon. A public exploit named FalconFlank claims to escalate to SYSTEM privileges on fully up-to-date Windows systems running Falcon New CrowdStrike 'FalconFlank' zero-day grants SYSTEM privileges. There is no CVE attached and no KEV entry, so traditional vulnerability management will not flag it. If the claims hold, the impact is significant: the exploit targets a security agent that defenders rely on to catch everything else. The immediate step is not to wait for a scanner signature, but to assess which endpoints run Falcon, review available mitigation guidance from the vendor, and understand whether any local users already have enough access to attempt the escalation.

Breaches

The Thomson Reuters C-Track incident deserves attention because court data is not ordinary PII. An unauthorized party obtained files from the court case management platform, which is sold through West Publishing, affecting courts in eleven U.S. states, the U.S. Virgin Islands, and Ontario Thomson Reuters Court Software Breach May Have Exposed SSNs and Sealed Data. A subset of the records may contain names and Social Security numbers, and the exposure of sealed court documents would create harm beyond identity theft, including risks to litigants, witnesses, and ongoing legal proceedings. Organizations using C-Track should treat the disclosure as a trigger to review which records were involved, whether local notification obligations apply, and what access controls exist around the most sensitive case files. For everyone else, it is a reminder that the justice system increasingly runs on commercial software with the same vulnerabilities as any other enterprise stack.
