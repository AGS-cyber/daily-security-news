Remote management and remote-access channels under fire

The day’s most urgent stories converge on a single theme: attackers are going after the channels that administrators themselves trust most. Active exploitation is forcing emergency action around a managed-service provider remote management platform, a cross-platform e-commerce framework, and internet-exposed routers, while fresh public exploit code is raising the pressure on endpoint and remote-support products. A large education-sector breach and research into an MFA-bypassing phishing service round out the picture.

Actively exploited

Managed service providers should treat N-able’s emergency hotfix for N-central as an immediate-deployment event rather than part of the normal patch cycle. Attackers are actively exploiting a maximum-severity remote code execution vulnerability in the remote monitoring and management platform N-able patches max severity N-central flaw amid ongoing attacks. N-central is the administrative path MSPs use to reach customer endpoints and servers, which means a single compromise can put the service provider and every downstream client in the critical path. The sensible assumption is that this is not a vulnerability to watch, but one to close as quickly as possible.

E-commerce defenders are dealing with a similar sense of urgency, but with an extra complication: the affected platform is under active attack before any remediation is available. A zero-day dubbed StyleSmuggler affects all versions of Magento and Adobe Commerce and is being exploited to deploy a Linux backdoor Magento StyleSmuggler zero-day exploited to deploy Linux backdoor. Given the all-versions scope, operators of exposed online stores should assume a breach rather than waiting for definitive signs of compromise. The backdoor deployment also means the priority is not only re-issuing credentials and rotating keys; it is hunting for persistence before applying any update.

On the network edge, attackers are exploiting a chain of two recently disclosed MikroTik RouterOS flaws to hijack routers that have SSH exposed to the internet Hackers exploit new MikroTik RouterOS flaws to hijack routers. The technique matters beyond MikroTik specifically: edge equipment is increasingly being used as a quiet initial foothold, and a router compromise can give attackers visibility into internal traffic, a platform for lateral movement, and a persistent presence that many organizations do not monitor. Defenders running affected devices should review internet-facing SSH exposure immediately and look for unauthorised configuration changes or unexpected logins.

Vulnerabilities

Public proof-of-concept code is not always news by itself, but it becomes operationally significant when it targets privileged software and produces SYSTEM-level access. That is the situation with a release dubbed Nightmare Eclipse, which drops zero-day privilege-escalation exploits for CrowdStrike, Nvidia, and Avast; the proof-of-concept chains spawn a shell with System privileges Nightmare Eclipse Drops CrowdStrike, Nvidia, Avast Zero-Day Exploits. Elevation of privilege is the missing link in many attacks that start with a compromised user session, and making those exploits public means defenders should treat the affected products as a priority for monitoring and for vendor guidance on fixes.

Remote-support software continues to be a particularly uncomfortable vulnerability class. ConnectWise has disclosed a new ScreenConnect Remote Access flaw and has said a patch is forthcoming, but for now only temporary mitigations are available ConnectWise warns of new ScreenConnect flaw without patch. Remote-support agents are installed with high privileges by design and often live on the network perimeter, which makes them an attractive target for anyone looking to gain remote interactive access. Organisations running ScreenConnect should determine which instances are internet-accessible and decide whether the temporary mitigations are sufficient or whether exposure should be reduced until the patch lands.

A separate proof-of-concept revives attention on older application components. TantoSec has published a working exploit chain that turns an AES-CBC padding oracle in Telerik UI for ASP.NET AJAX into unauthenticated remote code execution Telerik UI Padding-Oracle Bug Chained to Unauthenticated RCE — Public Exploit Released. Two details should shape the response. Progress has already patched the underlying chain in an earlier release, and the exploit only works against a specific non-default application configuration. There are also no confirmed reports of exploitation in the wild. Even with those limits, the public code is a reminder that application components embedded in custom software often lag behind vendor updates, and that “non-default” configurations are far more common in practice than their name suggests.

Breaches

The education sector is absorbing another large data exposure, this one from an internal reporting platform rather than a core learning system. Mathspace has disclosed that attackers stole data belonging to more than one million students, staff, and parents after breaching its Metabase internal reporting system Mathspace discloses data breach affecting over 1 million people. The incident illustrates why analytics environments deserve the same security attention as primary databases: they aggregate personal information from across the organisation, and they are often connected to multiple upstream sources. For a population that includes minors, the risk goes beyond credential theft to longer-term identity fraud, so affected individuals should be offered monitoring and clear guidance.

Research

New phishing research suggests that the term “MFA bypass” understates the operational problem. A phishing-as-a-service framework called BigBear 2.0 has been used to bypass multi-factor authentication at 258 organisations and steal more than 5,000 Microsoft 365 credentials BigBear Microsoft 365 phishing service bypassed MFA at 258 organizations. The scale is the story: phishing kits have moved from opportunistic credential harvesting to reliable, repeatable attacks against accounts that organisations believe are protected. For defenders, the takeaway is that all MFA is not equal, and that users with access to sensitive systems should be moved toward phishing-resistant authentication wherever it is supported. Any organisation that has seen suspicious Microsoft 365 logins from unfamiliar infrastructure should treat those as possible indicators of this style of attack.
