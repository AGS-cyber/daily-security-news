Actively exploited

The lead story is CVE-2026-69836, a CVSS 10.0 remote code execution vulnerability in Microsoft Entra ID that Microsoft says has already been exploited in the wild Microsoft Entra ID Flaw (CVSS 10.0) Exploited in Wild, Allows Remote Code Execution. It is a deserialization flaw in the identity and access management service, and the unusual part is that Microsoft says no customer action is required. That leaves monitoring and awareness as the primary defenses, since there is no customer-applied patch to track. The vulnerability is not yet in CISA's Known Exploited Vulnerabilities catalog, so the in-the-wild signal is coming from the vendor's advisory rather than from a catalog listing.

GitLab's CVE-2026-19478 is close behind. The CVSS 9.4 code injection flaw, reachable by an unauthenticated attacker through a GraphQL directive, can let an attacker modify or delete public projects and user data under certain conditions GitLab CVE-2026-19478 Comes Under Active Exploitation Within Days of Disclosure. Researchers report active exploitation within days of disclosure, and defenders should not wait for a KEV listing to treat it as urgent. The affected versions run from GitLab CE/EE 18.2 before 18.11.11 and the 19.0, 19.1, and 19.2 lines before 19.0.8, 19.1.6, and 19.2.4; the patched releases are the priority.

CISA has directed immediate patching for TrueConf vulnerabilities that the Head Mare hacktivist group is exploiting to deploy the PhantomCore malware CISA Urges Immediate Patching of Exploited TrueConf Vulnerabilities. The agency's urgency is warranted because these are not theoretical bugs: the attack group is already using them in active operations, so any organization exposing TrueConf endpoints should move remediation ahead of routine maintenance.

Zimbra adds another actively exploited target. CVE-2026-73570 is a CVSS 8.9 command injection vulnerability in Zimbra Collaboration before 10.1.20 that leads to unauthenticated remote code execution, but only when the optional zimbra-snmp package is installed and SNMP notifications are enabled; the attack arrives via specially crafted SMTP requests during SNMP notification processing Attackers Exploit Zimbra SNMP Flaw for Unauthenticated Remote Code Execution. CERT Polska has confirmed in-the-wild exploitation, so real attackers have already worked out the conditional path. Organizations running Zimbra should verify whether the SNMP package is enabled and patch to 10.1.20 or later.

Research

The Rust supply-chain compromise shows how trust in a package registry can be weaponized. Compromised maintainer credentials published malicious versions of arrayref 0.3.10, internment 0.8.7, and append-only-vec 0.1.9, which have a combined 245 million downloads Rust Supply Chain Attack Puts Build-Time Malware in Crates with 245 Million Downloads. The malicious releases pulled in a typosquatted dependency whose build script downloaded and executed a remote payload at compile time. That means every project that built against the poisoned versions became a potential malware distribution event, and the crates have now been removed from crates.io. The incident argues for treating build-time behavior as an attack surface and auditing dependencies for typosquatting and pre/post-build scripts.

Breaches

The SickKids disclosure shows how a third-party software flaw can put an organization's sensitive data at risk even when core systems are spared. Toronto's Hospital for Sick Children says the incident exposed personal information belonging to some current and former employees and job applicants SickKids data breach exposes employee and job applicant info. Clinical systems and patient records were not affected, which limits immediate patient-safety impact, but the breach still hits HR and operational data. For healthcare security teams, a vendor vulnerability in an administrative system can be as consequential as one in a clinical device.

Vulnerabilities

A critical sandbox escape in isolated-vm is a serious problem for any application using the open-source library to run untrusted JavaScript. The flaw, tracked as GHSA-864f-rcv7-6rh4 and not yet assigned a CVE, affects all versions before and including 7.0.0 Isolated-vm Flaw Lets Sandboxed JavaScript Escape to Host for Potential RCE. Because isolated-vm's entire purpose is to contain untrusted code, an escape defeats the security model and can lead to remote code execution on the host. The library's popularity makes the exposure broader than it might otherwise be, and the missing CVE makes tracking harder, so teams should inventory where isolated-vm is used and treat the affected version range as critical.

Cisco's latest round of patches covers nine vulnerabilities in Crosswork and Secure Workload Software, five of them carrying CVSS scores of 10.0 Cisco Patches Nine Crosswork and Secure Workload Flaws, Five Scoring CVSS 10.0. Four of the flaws affect Crosswork Data Gateway, Crosswork Network Controller, and Crosswork Planning regardless of device configuration, removing the usual configuration-based exposure arguments. These are management-plane platforms and therefore high-value targets. Organizations running any of these products should move the updates to the front of the queue.
