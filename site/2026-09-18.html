An unauthenticated RCE in Orkes Conductor is already being used against exposed instances, Microsoft shipped a maximum-severity fix for Azure AI Foundry, and Check Point's management plane needed a root-level patch. Meanwhile two breaches show how a single ancillary service becomes the entry point, and a long-running DDoS-for-hire operation went dark.

Actively exploited

The lead story is the one with a clock on it. An unauthenticated remote code execution flaw in Orkes Conductor, CVE-2026-58138, is being used in attacks, and the vulnerable window covers every release from 3.21.21 up to but not including 3.30.2 Critical Orkes Conductor Vulnerability Exploited in Attacks. The mechanics are worth understanding because they generalise: attackers submit inline workflow definitions containing malicious JavaScript or Python expressions to the workflow API before authenticating, and the engine evaluates them. The NVD description pins the root cause on unsandboxed GraalVM evaluators configured with HostAccess.ALL or allowAllAccess(true), reachable through the INLINE, LAMBDA, DO_WHILE and SWITCH task types, with code injection (CWE-94) as the assigned weakness Critical Orkes Conductor Vulnerability Exploited in Attacks. From there, arbitrary system commands follow via Java reflection or direct subprocess calls. The CVSS 4.0 base score is 9.3, critical, with no privileges or user interaction required Critical Orkes Conductor Vulnerability Exploited in Attacks.

If you run Conductor, the immediate work is inventory, not analysis: anything internet-exposed below 3.30.2 is the priority, and the upgrade path is unambiguous. The broader lesson is that orchestration engines which evaluate expressions are code-execution surfaces by design, and "workflow definition" is just a payload format. If you can't patch today, removing authenticated-before-evaluation assumptions from your exposure model matters more than tuning the WAF.

Vulnerabilities

Microsoft's fix for CVE-2026-85889 in Azure AI Foundry is a CVSS 3.1 score of 10.0, arising from a missing authentication check for a critical function (CWE-306) that lets an unauthorized attacker elevate privileges over the network Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Unauthorized Privilege Escalation. Microsoft's position is that no customer action is required, and for the platform itself that may well be true. The reason a 10.0 still deserves your attention is pattern-matching: an unauthenticated, privilege-granting function reachable over the network is rarely the only one, and the same architectural mistake tends to appear in adjacent internal tooling. Treat this as a prompt to enumerate which of your own privileged functions are reachable pre-authentication, and to confirm you have telemetry that would show abuse before a patch landed.

Check Point's problem is more directly actionable for anyone with its gear in the enforcement path. A critical flaw in the Security Management and Log Servers allows an attacker with no credentials to run code as root on those servers over the network Critical Check Point Management Flaw Lets Unauthenticated Attackers Run Code as Root. That matters because the management server holds firewall policy and administrator access — root there is effectively control of the estate's enforcement layer, not just another box. Check Point has pushed a fix through its LivePatch channel and says it has no indication the flaw has been exploited Critical Check Point Management Flaw Lets Unauthenticated Attackers Run Code as Root. No CVE identifier was supplied with the story, so track it by vendor advisory and patch channel rather than by ID. Prioritise any deployment where the management interface is reachable from untrusted networks.

Plugin4Shell is the quiet one that will outlast the rest. A flaw across four widely used AI coding agents lets whoever controls a plugin's code repository swap the plugin an agent installs for a malicious one, even when the agent pinned that plugin to a specific reviewed version Plugin4Shell Lets Repository Owners Swap Pinned Plugin Code Across Four AI Coding Agents. Air Security reported it; Anthropic has patched Claude Code 2.1.179 and OpenAI has patched Codex 0.146.0, while GitHub Copilot has no fix Plugin4Shell Lets Repository Owners Swap Pinned Plugin Code Across Four AI Coding Agents. The word "pinned" doing no work here is the story. Treat agent plugin sources with the same suspicion you apply to package registries: provenance, review, and an inventory of what each agent has actually pulled and executed.

Breaches

Two incidents, one shape. Gyazo maker Helpfeel disclosed that 23 million user records were compromised after an attacker exploited a vulnerability in its image upload server to gain unauthorized access 23 Million User Records Compromised in Gyazo Data Breach. A screenshot service is not a crown-jewel system, which is exactly why it's a good entry point — nobody was watching it the way they watch the identity provider. Ask which of your services exists purely to accept user files, and whether anyone would notice it being used as a pivot.

The Brevo incident is the third-party script problem at scale: attackers used a compromised Cloudflare API key to deploy a Cloudflare worker that injected malicious scripts into roughly 100,000 websites Brevo Supply Chain Attack Injects Malware Into 100,000 Websites. The victims' own code was fine; their vendor's key wasn't. Controls that actually help here are key scoping and rotation, content security policy strict enough to break unexpected injections, and monitoring that alerts when what your site serves changes without a deploy. Assume your marketing, analytics and support vendors are all writing into your pages.

Research

RatHat, a new Android malware family, is worth a look less for its current capability than for its direction New RatHat Android malware uses AI to automate device control. It pairs an AI-powered subsystem that helps operators remotely navigate a compromised device with a shell maintained over ADB that survives uninstall New RatHat Android malware uses AI to automate device control. Both halves lower the barrier: the AI component reduces the skill needed to operate an infected handset, and ADB-based persistence defeats the uninstall reflex users have been taught. For defenders on mobile, the practical takeaway is that "reinstall the app" is no longer a remediation step, and device-level monitoring needs to survive it.

Industry

An international operation has disrupted NightmareStresser, one of the longest-running DDoS-for-hire services in the world and active since at least 2022 NightmareStresser DDoS Service Disrupted in International Operation. Removing booter capacity raises the cost of entry for the low end of DDoS — the kind that arrives because someone was annoyed, not because anyone mapped your network. Expect displacement rather than elimination: capacity moves, brands rebrand. The useful check is whether your volumetric and application-layer defences have been exercised this year, because the demand doesn't disappear when a service does.
