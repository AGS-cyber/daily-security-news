A KEV-listed PAN-OS authentication bypass with confirmed ransomware use leads today, with Qilin and INC operators still using it for initial access. Behind it: autonomous AI agents run against more than 1,200 websites, a new APT28 loader aimed at the defense industrial base, a public proof-of-concept for a critical FortiSIEM path traversal, and a Siemens DLL-sideloading flaw the vendor says is live in ClickFix lures. ConnectWise's Cloud Backup remains offline, an OVHcloud CLI release was poisoned for up to 94 minutes, and DHS has ordered DeepSeek out of federal civilian systems.

Actively exploited

CVE-2026-0257 is a High-severity authentication bypass (CVSS 4.0: 7.8, CWE-565) in the GlobalProtect portal and gateway of PAN-OS, with a network-reachable vector requiring no privileges and no user interaction. The impact is narrow but valuable: bypassing security restrictions to establish an unauthorized VPN connection. Panorama and Cloud NGFW are not affected. The flaw is in CISA's KEV catalog with known ransomware campaign use, and Qilin and INC operators are reported to be using it to stand up rogue VPN sessions against a fix that has already shipped Qilin and INC Ransomware Groups Exploit Palo Alto Networks Flaw to Bypass MFA. CISA's required action is vendor mitigations or discontinuation of the product, with a federal remediation due date — a US federal deadline, not a universal one. Analysis: the 7.8 undersells this. A patched, KEV-listed edge-device bypass that still yields initial access for extortion crews means unpatched GlobalProtect portals remain an active entry point; the supplied reporting does not say how many remain exposed or how victims were selected.

Siemens has fixed a DLL-sideloading flaw in Software Center, CVE-2026-110936 (CVSS v4: 8.4, High, CWE-427), affecting versions below V4.0.9.8, and says it has been exploited in ClickFix attacks to deploy a remote access trojan ClickFix Attackers Exploit Siemens Software Center Flaw to Deploy Remote Access Trojan. Worth reading the vector carefully: the NVD record describes an authenticated local attacker with high privileges placing a crafted DLL in a directory the application searches, so the flaw is the execution step rather than the lure — the ClickFix social-engineering stage supplies the user action the CVSS vector does not capture. It is also a confirmed KEV miss despite the vendor's exploitation statement, which is a reminder that catalog absence is not evidence of safety.

Research

A Chinese-speaking criminal pointed autonomous AI agents at company websites with almost no human help, and the campaign is unusually well documented because the operators left their control panels exposed on the internet Hackers Use Autonomous AI Agents to Breach Company Websites, Target Over 1,200 Sites. The agents attempted more than 1,200 sites and reached websites belonging to more than 100 companies, including an industrial manufacturer and an appliance maker. No CVE is involved; the story is the economics. Analysis: agentic tooling collapses the cost of trying 1,200 targets, and the leaked panels give defenders a rare view of how the targeting was sequenced — the supplied text does not say what the agents succeeded in doing after access.

APT28 has been attributed to attacks on two NATO member states, including a breach of a naval shipbuilder, deploying a backdoor called HOOKEDGE alongside a previously unseen reflective loader; researchers track the cluster as Swallowtail Russian APT28 Breaches NATO Naval Shipbuilder in NATO Country, Deploys New Reflective Loader. For anyone defending the defense industrial base, the loader and backdoor are the actionable part — new tooling means existing signatures are the wrong place to look.

Vulnerabilities

A public proof-of-concept now exists for CVE-2026-106173, a path traversal (CWE-22) in FortiSIEM that permits unauthenticated remote code execution Critical FortiSIEM Flaw Gets Public Exploit PoC for Unauthenticated Remote Code Execution. The severity figures in the supplied material disagree: reporting gives 9.4, while the NVD record carries CVSS 3.1 at 9.8 — both Critical, and the NVD description names FortiSIEM 7.5.0. Either way this is a patch-now item for anything exposing the platform, because the PoC lowers the skill floor. It is a confirmed KEV miss; the supplied evidence does not report in-the-wild exploitation, and the PoC's mechanics are not described.

Breaches

ConnectWise says it has strengthened administrative-access protections and is resetting accounts and replacing application credentials after unauthorized access to application identities associated with Cloud Backup, which remains offline ConnectWise Resets Credentials as Cloud Backup Remains Offline After Security Incident. Analysis: the unresolved question for partners is downstream — MSP tooling and Microsoft 365 tenant exposure is what should be scoped now. The supplied material does not state whether customer data was accessed or how many partners are affected.

An attacker used a hijacked contributor account to replace the download archives on five existing OVHcloud CLI releases with a build designed to steal secrets stored on disk Hackers Hijack Five OVHcloud CLI Releases to Distribute Secret-Stealing Malware. The malicious files were live for up to 94 minutes, from 12:47 to 14:21 UTC. Short windows are not reassuring here: mirror caches and CI pipelines that pulled during that gap keep the tainted artifact long after the releases were pulled.
