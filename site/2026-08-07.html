MFA-Bypassing Phishing, a Linux Container Escape, and the New Default Attack Surface

8 of 21 stories written up · 12 of 12 sources · generated 12:51 UTC

Widespread adversary-in-the-middle phishing is targeting Microsoft 365 financial mail, a long-lived Linux SCTP flaw can give root and container escape, and new research shows coding agents and AI-assisted HTTP fuzzing are expanding the default attack surface. Add a 3.8 million-record health-data breach and a self-propagating npm worm to the pile.

Actively exploited

The lead story is a widespread email-driven phishing campaign that uses adversary-in-the-middle techniques to take over Microsoft 365 accounts. Microsoft 365 AitM Phishing Hijacks Accounts to Collect Payroll and Finance Emails The attackers are not just after credentials; they are selecting accounts involved in financial workflows and pulling payroll and finance email to understand who approves payments and where funds move. They are routing the malicious sign-ins through residential proxies to make the traffic look like ordinary consumer activity, which is a useful reminder that IP reputation alone cannot be trusted as a risk signal. Organisations should treat any sign-in from a residential-looking proxy as worthy of review, push for phishing-resistant MFA, and inspect sign-in risk before the next payroll cycle.

macOS users are also being hit by a live ClickFix campaign dropping a Go-based infostealer. ClickFix attack pushes macOS infostealer for crypto theft attacks The payload steals cryptocurrency assets, browser-stored passwords, Apple Keychain data, and cached credentials. ClickFix's social engineering — faking a browser interaction or CAPTCHA to coax a paste-and-run — has become a common initial-access method, and this campaign shows the consequences when it lands on a machine holding wallet keys and development credentials. This is a reminder that the macOS security model does not protect against a user who has been talked into running something.

Vulnerabilities

The most serious vulnerability story is a use-after-free in Linux's SCTP networking code. 18-Year-Old Linux SCTP Flaw Could Let Local Users Gain Root and Escape Containers The bug has survived for more than fifteen years and can be exploited for local privilege escalation to root; researchers also used it to escape a container and compromise the host. The fix has already shipped in stable kernel updates, so the burden is on operators to identify systems with SCTP reachable and patch them before public exploit development catches up. For container workloads, this is a particularly uncomfortable finding because it breaks the isolation boundary that many deployments rely on as a security control.

Also in the vulnerability space is new HTTP desynchronization research. AI-Assisted HTTP Terminator Finds Novel HTTP Desync Techniques and Apache Zero-Day An AI-assisted research system explored 30,000 candidate desync vectors and produced novel HTTP request-smuggling techniques, while a separate human-guided effort uncovered a zero-day in Apache Traffic Server. The significance is not just the specific zero-day: the workflow demonstrates that AI can help discover entire classes of protocol-level bugs, which will almost certainly be adopted by attackers as well. Anyone running Apache Traffic Server should treat the situation as urgent, but the wider lesson is that HTTP parsing discrepancies between front-ends and back-ends remain a deep source of exploitable bugs.

Browser patching also deserves attention. The latest Chrome update fixes more than two dozen memory-safety bugs, including critical use-after-free issues. Critical Vulnerabilities Patched With Chrome 151 Update Browser memory-safety bugs are the closest thing we have to a reliably exploitable remote attack surface, and the gap between a public fix and a known exploit is often short. Managed fleets should force-restart the browser rather than wait for the next user reboot.

Finally, researchers have shown that coding-agent defaults are a new vulnerability class. Claude Code and Gemini CLI Flaws Let a GitHub Issue Reach CI Workflow Secrets In the default configurations used by Anthropic and Google, a GitHub issue opened by an account with no repository privileges was enough to execute code on CI runners and steal workflow secrets; on OpenAI's agent, it allowed hijacking the next agent run. The key detail is that the attack worked in the vendor-shipped default configuration, so this is a configuration problem as much as an implementation bug. Teams adopting agentic coding tools need to treat issue trackers and pull request content as untrusted input, and should scope CI workflow secrets as narrowly as possible.

Breaches

The breach report of the day concerns a data center compromise affecting 3.8 million people. 3.8 Million Impacted by Unlimited Technology Systems Data Breach The stolen records include personal, medical, and health insurance information. Medical and insurance data create durable fraud risk because, unlike stolen credit cards, they cannot be rotated and they remain valuable for years. Affected individuals should watch for suspicious insurance claims and identity-theft warnings. For security teams, the incident is a reminder that data center access and storage-layer controls can be the last line of defense when application security fails.

Research

Lastly, ChainDrop is a self-propagating npm worm that extracts GitHub Actions runner secrets and uses Ethereum smart contracts as a command-and-control routing mechanism. ChainDrop: Inside a Self-Propagating npm Worm Self-propagation makes supply-chain attacks self-spreading, and stealing Actions runner secrets gives an attacker a way into the release pipeline itself. The choice of Ethereum for C2 is notable because blockchain-based infrastructure is durable, public, and hard to take down. Package registries and CI systems should be treated as production infrastructure: short-lived credentials, separate runners for untrusted code, and monitoring for unexpected package publication.
