Enterprise Flaws Under Active Attack: SAP, VMware, macOS, and GeoServer Demand Urgent Action

8 of 33 stories written up · 12 of 12 sources · generated 12:33 UTC

Today's briefing covers four actively exploited vulnerabilities—including a maximum-severity SAP Commerce Cloud bug and an unpatched GeoServer SQL injection—plus a major Azure data theft claim, two unpatched privilege escalation issues, and Mustang Panda's new signed rootkit. If you run any of the affected products, the active-exploitation section is your priority.

Actively exploited

The lead story is SAP Commerce Cloud, where CVE-2026-58231 is already under attack three days after disclosure. The flaw has a CVSS 10.0 and lets an unauthenticated attacker abuse a default authentication client to send specially crafted input to insufficiently validated functions, leading to arbitrary code execution and compromise of internal components. For an e-commerce platform, that is as bad as it gets: exploitation is straightforward, the impact spans confidentiality, integrity, and availability, and the short gap between disclosure and attacks means organizations should treat this as an emergency and apply SAP's patch immediately Critical SAP Commerce Cloud Vulnerability Exploited 3 Days After Disclosure.

The second active exploit is in VMware vCenter. CVE-2026-59310 is a critical directory traversal in the Syslog server, carrying a CVSS 9.8 and allowing a network attacker to execute arbitrary code. Researchers attribute the exploitation to a suspected China-nexus APT, and the observed payloads are Babuk-derived ransomware. vCenter is a particularly attractive target because it sits at the control plane of virtualized infrastructure; a compromise here can lead to encryption of many workloads at once. Enterprises with vCenter should patch this immediately Suspected China-Nexus Actor Exploits VMware vCenter Flaw, Deploys Babuk-Derived Ransomware.

Apple's macOS Screen Sharing is also being exploited in the wild. CVE-2026-65400 is an authentication issue (CWE-287, CVSS 9.8) that lets an attacker on the network authenticate to Screen Sharing without valid credentials. The observed campaign has been installing a Monero miner on internet-exposed Macs, which suggests broad opportunistic scanning, but the real danger is that the same bypass could be used for data theft or further compromise. Patches are available for the macOS Sequoia, Sonoma, and Tahoe lines; apply them without delay Apple macOS Screen Sharing Flaw Exploited on Internet-Exposed Macs to Install Monero Miner.

Finally, GeoServer is the subject of a zero-day SQL injection vulnerability that researchers say is seeing active exploitation attempts. The flaw has not yet been assigned a CVE and remains unpatched. Because SQL injection in GeoServer can lead to remote code execution, this is a serious risk for any organization exposing GeoServer to untrusted traffic. Until a patch lands, treat it as urgent and consider restricting access to the GeoServer endpoint; with no fix available, network-level containment is the main mitigation GeoServer Zero-Day Targeted in Active Exploitation Attempts, Can Lead to RCE.

Worth noting: the three CVEs in these active-exploitation reports are not currently listed in CISA's Known Exploited Vulnerabilities catalog, so relying on that list as a triage filter would have missed these attacks. It is a useful reminder that KEV membership is a floor, not a ceiling, for prioritization.

Breaches

A threat actor is claiming to have exfiltrated millions of records from several large organizations, including McDonald's, TCS, and Vodafone, in what is described as an Azure data theft campaign. The claim should be treated as unverified until data is released or confirmed, but the named organizations and the broader Azure customer base should take it seriously. Any company using Azure should look for signs of unauthorized data access, review identity and configuration posture, and watch for extortion or further disclosure Fortune 500 Companies Hit in Azure Data Theft Campaign.

Vulnerabilities

Microsoft has confirmed the "ShieldBreak" zero-day in the Microsoft Malware Protection Engine used by Defender, tracked as CVE-2026-69414. The vulnerability is a local privilege escalation with a CVSS score of 7.8, and Microsoft says it is working on a patch. Exploitation requires local access, making it most useful as a post-compromise escalation step, but the fact that it affects a security product means an attacker who lands on a system can quietly elevate privileges and potentially disable or bypass defenses. There is no fix available yet; monitor Microsoft's update channel and treat any Defender anomalies as suspicious Microsoft working on Defender patch for ShieldBreak zero-day.

Separately, researchers have published a two-stage exploit chain against Unisoc modem firmware that ends in full Android kernel access via a VoLTE video call. The first stage provides remote code execution in the modem; the second stage escalates to a complete kernel compromise. The chipset maker has not released a fix. This is a particularly difficult issue to defend against because the initial attack surface is the modem, not the application processor, and users cannot easily disable VoLTE without losing service. Android devices with Unisoc modems are exposed until a fix is made available Unisoc VoLTE Video Call Exploit Chain Can Give Attackers Full Android Kernel Access.

Research

Mustang Panda, also tracked as HoneyMyte, has updated its CoolClient backdoor with a signed Windows kernel-mode rootkit. The rootkit is designed to hide and protect malicious processes, files, registry objects, and C2 information, making infected systems significantly harder to clean. Researchers observed victims in Myanmar, Mongolia, Pakistan, and other countries. The use of a signed driver is noteworthy: even if the signature is later revoked, the capability demonstrates how espionage actors are investing in stealth mechanisms that evade traditional endpoint detection Mustang Panda Adds Signed Windows Rootkit to CoolClient Backdoor for Stealth.
