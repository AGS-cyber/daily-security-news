CISA's KEV update leads a day of compromised or exposed management infrastructure: Check Point management servers at 22 organizations, a 9.8 vCenter authentication bypass in a 23-flaw VMware batch, and an Azure APIM hunt for tokens and secrets. Radware's exposed API, a no-login WHMCS SQL injection, KEPCO's 1.5 million-person breach and an Iran-aligned group's IPFS-backed backdoor fill out the picture.

Actively exploited

CISA added two flaws to its KEV catalog, one affecting N-able MailAssure and one affecting MONAI Label, citing evidence of active exploitation Hackers Exploit N-able MailAssure Flaw While AI Agents Exploit MONAI Label Zero-Day. The supplied enriched record covers CVE-2026-134624, a Critical 9.3 SSRF (CWE-918) in MailAssure's LDAP synchronisation connection check; NVD says an authenticated API user can make the server connect to arbitrary internal hosts and ports, determine reachability and send crafted data to internal services, with versions before 20261121.1943 affected. CISA's required action calls for vendor mitigations under BOD 26-04, or discontinuing use where mitigations are unavailable; that is a federal compliance path, not a universal deadline. The MONAI Label flaw's CVE and severity were not supplied. Separately, threat actors exploited multiple vulnerabilities to compromise two dozen Check Point Security management servers at 22 organizations in an ongoing campaign Hackers compromise Check Point Servers in 22 organizations. The excerpt does not name the CVEs or actor. Analysis: the management plane is the issue — compromising security infrastructure turns it into an intrusion path.

Vulnerabilities

Broadcom patched 23 vulnerabilities across VMware ESX, vCenter, Workstation, Fusion and Avi Load Balancer, including CVE-2026-123903, a 9.8 authentication bypass in VMware Directory Service ("vmdir") VMware vCenter Hit by Another Critical 9.8-Rated Auth Bypass Flaw After Zero-Day Exploitation. The supplied data records knownExploited as false and no NVD record; that is a KEV catalog miss, not proof that exploitation has not occurred. Analysis: a 9.8 directory-service authentication bypass in vCenter warrants urgent virtualization admin review, though the excerpt truncates the attacker prerequisites. Norway's NSM disclosed an Azure API Management flaw that affected multiple businesses, including Equinor and Skagerak Energi; it said an unknown actor has actively looked for access tokens, secrets and named values in APIM, and Microsoft has fixed the flaw Microsoft Fixes Azure API Management Classic Flaw as Actor Targets Customer Secrets. The excerpt leaves the intrusion path unresolved. Analysis: token and secret hunting is the impact to prioritize. WHMCS disclosed a SQL injection that needs no login and could let anyone on the internet retrieve customer records and administrator password hashes from an installation's database, alongside two other flaws that require a logged-in client WHMCS SQL Injection Could Expose Customer Data and Admin Password Hashes without Login. Analysis: for hosting providers, billing-platform exposure reaches both client data and admin credential material.

Breaches

Radware says attackers accessed some customers' account details and cloud access keys through an unsecured internal Cloud WAF management API left exposed online Radware discloses breach exposing customer cloud access keys. The excerpt does not give the number of customers or the exposure window. Analysis: cloud keys turn a vendor-side API exposure into downstream customer risk. KEPCO suffered a breach affecting 1.5 million people, with personal information stolen from its customer portal and supplier relationship management platform 1.5 Million Impacted by Data Breach at South Korean Electric Company KEPCO. Analysis: the supplier-system element broadens the incident beyond retail customers; the excerpt does not describe the data types further.

Research

The group described as Volant Manticore, a previously undocumented Iran-aligned espionage group, targeted telecommunications companies, airlines and critical infrastructure in Cyprus Iran-Aligned Volant Manticore Uses IPFS-Based KuboShell Backdoor in Espionage Campaigns. Its KuboShell backdoor uses IPFS for command-and-control and deploys Homa, described as a post-compromise framework and a reimplementation of an unspecified framework. Analysis: IPFS-based C2 is a resilience choice that can complicate static blocking, but the supplied text does not detail its operational security.
