CISA confirms in-the-wild exploitation of an Ivanti Connect Secure flaw, Anthropic researchers build a remote-root Linux exploit, and several reports trace AI through both attacker and defender tooling.

Actively exploited

Ivanti Connect Secure flaws were added to CISA's Known Exploited Vulnerabilities catalog on evidence of active exploitation, with reporting describing attackers chaining three bugs to reach root on internet-facing gateways Attackers Chain Three Ivanti Connect Secure Flaws to Gain Unauthenticated Root Access. Only one is identified in the supplied material: CVE-2026-111357, carried there at CVSS 8.8 as a missing-authentication flaw. The NVD record for the same CVE is lower and narrower — 7.0 High, CWE-829, a local vector needing low privileges and no user interaction — describing 22.8R2.4 mishandling how the dsinvoked broker trusts DSCache configuration data to escalate to root, exploited in the wild. The 8.8 unauthenticated-network framing and the 7.0 local vector are unreconciled in the supplied text; treat the entry path as unconfirmed. Configurations run from 25.1.0.0 up to below 25.1.1.3, plus 22.8 R2 through R2.5. CISA's required action and due date bind federal agencies under a directive, not every operator.

Vulnerabilities

Researchers built a working exploit for a critical Linux kernel flaw in Multipath TCP that yields root-level remote command execution against servers exposing MPTCP listeners, with no authentication required Critical Linux kernel flaw allows remote root attacks on MPTCP servers. No CVE or version range is supplied, so triage starts from an inventory of hosts with MPTCP enabled rather than from a patch list.

Breaches

Chainalysis disclosed a breach in which attackers used what it called "offensive agentic techniques" to reach internal systems and tools, exposing customer names, email addresses, user IDs and organisational roles Chainalysis discloses data breach from "offensive agentic techniques". Analysis: the data is low-sensitivity identity material, but the method — described in the vendor's own words and not independently verified — is the point when the victim is a security vendor.

Research

A crafted ChatGPT share link could run attacker code inside the logged-in session of anyone who opened it and expose private conversations; the researchers reported it through a bug bounty, and it was rated P1 and fixed within eight days A Shared ChatGPT Link Could Run Attacker Code in Your Session and Read Private Chats. Share surfaces are the under-watched edge of assistant security: a link is the delivery mechanism, and trust in a familiar domain is the precondition.

CrowdStrike attributes a Go-based, AI-powered penetration-testing framework called ARTEX to a China-based targeted intrusion adversary it tracks as Vapor Panda, used against more than 200 organisations Chinese Hackers Use AI-Powered ARTEX to Target Over 200 Organizations Worldwide. A malicious Claude Code–branded extension, analysed alongside detection and remediation guidance, plants a persistent SSH backdoor Inside a malicious Claude Code-branded extension and its persistent SSH backdoor. Analysis: both ride legitimate developer and AI workflows, so extension and package provenance plus SSH persistence hunting are the levers.

Talos shows the self-deleting VOLTA infostealer taking credentials, sessions and crypto wallets, then using LLMs to profile victims and rank their most valuable assets Appraisal by AI: Model-driven victim prioritization in the VOLTA infostealer. Ranking inside the stealer collapses the gap between collection and monetisation.
