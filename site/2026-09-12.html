Actively exploited

Start with GitLab CVSS 10 File-Read Flaw Draws In-the-Wild Probes After Disclosure, because it is the least ambiguous story of the day. CVE-2026-85706 is a 10.0 — a path traversal (CWE-22) in the repository commits API that lets an unauthenticated attacker read arbitrary files from the GitLab server, the result of improper path confinement and missing authentication enforcement. The affected configurations are GitLab CE/EE from 18.7 before 19.1.8, 19.2 before 19.2.6, and 19.3 before 19.3.2. It is in CISA's KEV catalog as known-exploited, and the report describes in-the-wild probes landing within hours of disclosure. The CVSS vector is worth reading rather than skimming: scope-changed, confidentiality-high, integrity and availability unrated. That is a clean exfiltration primitive against a system whose filesystem is the family jewels — repositories, CI variables, runner tokens, deploy keys. CISA's required action, framed around BOD 26-04 with a due date a few days out, binds federal agencies; for everyone else the takeaway is tempo. Self-hosted GitLab is usually reachable, usually holds credentials with broad downstream reach, and rarely sits behind a WAF that understands this request shape. Patch, then rotate anything the process could read.

Artifactory flaws chained in attacks deploying backdoor malware is the sequel pattern: attackers chaining critical and high-severity Artifactory flaws to bypass authentication, escalate to administrative privileges, and drop a Rust backdoor on self-hosted servers. Note what is absent — no CVE identifiers or scoring accompanied this one, so treat the claims as source-reported rather than independently structured, and don't let anyone paraphrase it into a specific patched version. The architectural lesson holds regardless: an artifact repository is a trust root for your build pipeline, so admin access there is equivalent to write access to everything you ship.

Vulnerabilities

Dutch NCSC: Critical Check Point VPN flaws exploitation is imminent gives defenders a genuine head start, and the emphasis is on head start: the Dutch national cyber security centre says exploitation of CVE-2026-85102 and CVE-2026-85103 is imminent. Both are 9.8, both unauthenticated and remotely reachable, both aimed at Check Point Quantum. CVE-2026-85102 is CWE-295 — improper certificate trust validation during VPN negotiation, permitting arbitrary code execution on the gateway. CVE-2026-85103 is CWE-122 — a heap-based buffer overflow in VPN certificate ASN.1 decoding, reaching both Quantum Security Management and Quantum Security Gateway. Neither appears in CISA's KEV catalog; that is a statement about catalog contents, not evidence that nobody has tried. Pre-auth remote code execution on a VPN concentrator remains the single highest-leverage target class in enterprise security, because the device is deliberately internet-facing and the exploit is a single packet. Warning of imminent exploitation is the rare case where you get to patch before the incident report.

Breaches

Two identity failures, different flavours. Florida confirms DMV database breached via stolen police account is the blunt one: Florida's driver database was breached using credentials belonging to a police department employee, exposing a large government identity dataset. The access path is the story — a trusted external party's account, no novel exploit required. Driver records are durable, non-rotatable, and useful for years. Passkey-themed phishing attacks lead to Microsoft 365 data theft is the same theme with better tradecraft: Microsoft attributes passkey and single sign-on-themed social engineering to ShinyHunters, Helix and other extortion crews, used to compromise corporate accounts and lift data from Microsoft 365. Passkeys change the lure, not the objective; the winning move is still session or token theft after the user is talked past the prompt. If your passkey rollout didn't come with conditional access tightening and session-token revocation, you moved the lock and left the window.

Research

Two pieces worth your reading time for opposite reasons. OpenAI Agents Linked to RubyGems Campaign That Gained RCE on RubyDoc Servers ties the RubyGems campaign that achieved remote code execution on RubyDoc servers to a swarm of OpenAI agents, per a newly published research report. The interesting claim isn't the brand name on the model — it's tempo. If the campaign's discovery, payload iteration and targeting were machine-driven, the relevant control for maintainers is not better code review but tighter provenance and CI credentials: attacker throughput is now a variable. BlueMoon Exploit Kit Chains Recent Chrome, Windows Zero-Days documents the BlueMoon exploit kit chaining recently disclosed Chrome and Windows zero-days, adopted in opportunistic, rushed deployments by multiple espionage-motivated actors. Rushed is the operative word: the gap between patch release and weaponisation has compressed to the point where "we'll get to it in the next cycle" is an exploit window, not a backlog decision.

Industry

Finally, Anthropic Says Seven China-Based AI Labs Ran Industrial-Scale Claude Distillation Attacks: Anthropic says it identified and disrupted industrial-scale distillation attacks against Claude run by seven China-based labs, naming Alibaba, Moonshot, DeepSeek, Z.ai (Zhipu) and MiniMax. Distillation is legitimate machine learning — a large model teaching a smaller one — so the objection is scale, consent and terms, not technique. For security teams, the significance is that model access logs have quietly become a first-class telemetry source. Query volume, prompt-pattern clustering and account-multiplicity detection are the API-abuse analogue of impossible travel, and most organisations already emit that data without anyone watching it.

The day's through-line: three of these stories are about systems that hold trust for everything downstream of them — a Git server, an artifact registry, a VPN gateway — and all three are internet-facing by design.
