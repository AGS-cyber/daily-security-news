Actively exploited

The lead item is the KEV addition of WSO2 and Adobe Commerce Flaws Exploited in Attacks, Added to CISA KEV. CVE-2026-5430 is confirmed exploited and tracks CWE-347, improper verification of cryptographic signatures — the NVD write-up describes JWT authentication accepting tokens signed with algorithms it was never configured for, which an attacker turns into unauthorized access and potentially full account takeover. Note the metadata friction: the catalog entry labels the bug a path traversal, while the technical description reads as algorithm confusion. Triage accordingly rather than trusting the label. Severity is high by any measure — reported at 9.8, with a secondary CVSS 3.1 vector scoring 10.0 under a scope-changed assumption. The affected footprint is the real story: WSO2's API Manager, API Control Plane, Traffic Manager and Universal Gateway all appear across multiple 4.x ranges, meaning this is not a single-product patch but a platform-wide one. The accompanying Adobe Commerce/Magento flaw matters for anyone running storefronts with publicly reachable admin surfaces. Federal agencies are operating under a compressed remediation window tied to BOD 26-04, with explicit instructions to weigh internet exposure and to drop the product entirely if mitigations don't exist. If you're not federal, that timeline is still the right intuition: patch windows of hours, not weeks.

Roundcube Pre-Auth SQL Injection Flaw Actively Exploited in the Wild is the more instructive of the two. CVE-2026-48842 is a pre-authentication SQL injection in Roundcube's virtuser_query plugin, CVSS 8.1, CWE-89, fixed in 1.6.16 and 1.7.1 — and it is being exploited now. It is absent from KEV, which is a catalog miss, not evidence of calm. Pre-auth means no credentials required against an internet-facing mail server; the plugin has to be enabled, so check that first, then assume compromise and hunt for post-exploitation rather than just patch-and-move-on.

Breaches

Bitget Says Suspected North Korean Hackers Stole $351.6M After Backend Compromise is Bitget's own admission: unauthorized transfers from a limited number of hot and warm wallets, $351.6 million gone, suspected North Korean operators, cold storage and the bulk of platform assets untouched. Two things to take from it. Warm wallets are the interesting failure here — the middle tier between air-gapped cold storage and always-on hot keys is where operational convenience erodes custody discipline. And the cold-wallet line is being used as reassurance when it should be a question: if the backend that authorizes transfers is compromised, the distinction between hot and cold is a matter of what keys were reachable at the moment of the pivot. Treat this as DPRK fundraising, expect the stolen funds to be traced and frozen piecemeal, and expect copycat attempts against exchanges with similar wallet architectures.

Research

Compromised GitHub Actions Came Back Online and Resumed Executing Mini Shai-Hulud Malware is the case study in why supply-chain remediation is not a one-time action. Two actions-cool GitHub Actions — issues-helper and maintain-one-comment — became reachable again and resumed executing Mini Shai-Hulud malware months after the May campaign, and have now been disabled a second time. Anything that consumed those actions in the interim, or pinned a mutable ref, should be treated as a fresh exposure. Rotate workflow credentials, review cached artifacts, and audit who touched the pipeline since the re-enable — the point is that upstream takedown and downstream cleanliness are different problems.

New Carbonato malware uses AI agents to hijack exposed Docker hosts describes Carbonato, a botnet that targets hosts running exposed Docker daemons and installs the Hermes Agent AI framework to take over. An unauthenticated Docker API is root on the host by design, which makes this a low-effort mass compromise, but the payload is the news: agent frameworks are now post-exploitation infrastructure, and the egress they generate — model provider APIs, tool calls — is a detection opportunity most networks aren't watching.

Vulnerabilities

‘SalesBleed’ Flaws in Salesforce Agentforce Enabled Zero-Click Data Exfiltration covers three flaws in Salesforce Agentforce collectively dubbed SalesBleed, reportedly enabling zero-click data exfiltration by hijacking trusted agents that then also serve as phishing infrastructure. The mechanism is less important than the trust model: agents carry standing OAuth grants and reach into CRM data, so an attacker who controls an agent's instructions inherits its permissions without ever touching a credential. Review what your agents can reach, and whether their outputs are treated as trusted content.

Unpatched OnePlus Flaws Let Installed Android Apps Gain Root Without Permissions is the one that will still be open next month. Two chained flaws in OnePlus's own software let an installed app with no special permissions gain root on a OnePlus 15 running current OxygenOS; the researcher who found it was told the same issues affect many more OnePlus devices and a set of OPPO models. It is unpatched, no CVE is attached, and the prerequisite — a user installs an app — is not much of a barrier given how often sideloading and third-party stores are part of the threat model. Assume root-capable malware on affected handsets.

Marketplace takedowns matter less than the records they generate — the plea is useful chiefly for what it maps about buyers, sellers, and the tooling supply chain feeding both.
