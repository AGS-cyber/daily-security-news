Two unpatched attack chains demand immediate mitigation today, one aimed at online storefronts and one at exposed router management interfaces. JetBrains is asking Cadence users to rotate credentials after its own environment was breached through TeamCity, and Trezor has revised the scope of a shipping-provider incident upward. The research pipeline also brings a critical VMware hypervisor flaw, blockchain-hosted ClickFix payloads, invisible-Unicode URL smuggling, and a stealer that leaves a crypto miner behind.

Actively exploited

Store operators should assume the worst: a newly reported flaw in Magento Open Source and Adobe Commerce is already being used to backdoor online shops, and the campaign surfaced before the vendor had a patch ready. The issue, named StyleSmuggler by the Dutch e-commerce security firm that discovered it, lets an attacker run malicious code on the store’s server without logging in. Unpatched Magento and Adobe Commerce Zero-Day Exploited to Backdoor Online Stores That means the abuse surface is not a misconfigured admin account or a stolen credential but a direct, pre-authentication code-execution hole in a platform that powers large parts of the retail web. For merchants running Magento or Adobe Commerce, the practical implication is that any internet-facing instance should be treated as potentially compromised until the flaw is closed and indicators are checked for backdoors.

Router defenders are facing a similarly direct threat, though with a different root cause. CERT Polska warns that MikroTik devices with their SSH remote-management service exposed to the internet are being taken over without authentication, giving attackers full administrative control of the router. Attackers Hijack MikroTik Routers Through Internet-Exposed SSH Without Authentication The campaign is active and ongoing, and the absence of a clean one-line explanation should not reduce the urgency: management interfaces with no authentication requirement and internet reachability are effectively unlocked doors. Organisations running MikroTik equipment should immediately restrict SSH access to trusted networks, audit device configurations and user accounts, and assume that any router that was exposed may have been modified. Because routers sit at the network boundary, full control of one can mean redirected traffic, credential harvesting, and persistent access to everything behind it.

Breaches

JetBrains has confirmed that unidentified attackers exploited a recently disclosed critical vulnerability in TeamCity to break into the company’s own Cadence environment. Attackers Breached JetBrains Cadence via Unpatched TeamCity, Extracting AWS Credentials The incident exposed credentials and secrets tied to Cadence executions, including AWS credentials, and JetBrains is now instructing Cadence users to revoke or rotate anything that may have been used to run their workflows. The breach matters beyond the immediate credential rotation because it is a vendor self-compromise: the same CI/CD product JetBrains sells was the entry point into the infrastructure used to build and ship software. Users should treat JetBrains’ guidance as mandatory, not precautionary, and should audit any Cadence secrets, cloud keys, or deployment tokens that were active during the incident window.

Another breach notification is more about supply-chain data handling than software integrity. Trezor says an additional 67,000 U.S. customers were exposed in the breach at its shipping provider ShipMonk, bringing more personal data into an incident the company had previously suggested was limited in scope. Trezor Says ShipMonk Breach Exposed 67,000 U.S. Customers' Data It Said Was Deleted The exposed records include names, email addresses, phone numbers, shipping addresses, and order numbers for customers whose data Trezor believed had been deleted. The security of the hardware wallets themselves is not affected, but the leaked information is ideal material for targeted phishing, social engineering, and account-recovery attacks. Anyone who ordered a Trezor through affected channels should be wary of unsolicited messages referencing order details and should not treat knowledge of a shipping address as proof that a sender is legitimate.

Vulnerabilities

Broadcom has released updates for VMware Workstation and Fusion after fixing two flaws, including a critical integer-overflow vulnerability tracked as CVE-2026-59346 with a CVSS score of 9.3. Critical VMware Workstation and Fusion Flaw Lets VM Admins Execute Host Code An attacker with local, elevated privileges can exploit the bug to execute arbitrary code under certain conditions, and because Workstation and Fusion sit at the hypervisor boundary, the more worrying consequence is code execution on the host from inside a virtual machine. Hypervisor flaws of this kind deserve prompt patching even when no in-the-wild exploitation is confirmed, since they are routinely chained with guest-level compromise to escape sandboxes and reach the underlying operating system. Virtualisation admins should treat the update as priority work, especially in security-sensitive environments where untrusted code is run inside VMs.

Research

A large-scale criminal operation has compromised more than 5,400 small-business websites to deliver ClickFix payloads, but with a twist designed to frustrate takedowns: the malicious payloads are stored in smart contracts on BNB Smart Chain. Over 5,400 hacked sites serve ClickFix payloads stored on the blockchain Hosting attack content on a blockchain makes the infrastructure significantly harder to dismantle than a conventional command-and-control domain, since the data lives on a distributed ledger rather than a single server. Website owners should check their sites for unexpected injected scripts, and defenders should treat blockchain-stored payloads as a growing evasion pattern rather than a one-off curiosity.

Phishing continues to evolve in a lower-level way as well. Attackers are now using invisible Unicode characters to conceal malicious URLs from email security filters, a technique sometimes described as ASCII smuggling. Attackers conceal phishing lures using invisible Unicode characters The approach works because the characters are not visible when the message is rendered, allowing a link to look benign while pointing somewhere malicious. Filters that inspect the visible text, rather than the underlying character stream, can be bypassed, and users who read the email cannot easily see that the destination does not match its apparent target. This is another reminder that URL reputation and display-text checks are insufficient on their own; link analysis needs to account for what the human cannot see.

Finally, Elastic Security Labs has documented four previously unreported modules associated with REVSTEALER, an emerging Windows information stealer. Four REVSTEALER-Linked Modules Disable Windows Update and Defender to Run a Crypto Miner The modules — named ProManager, WinUpdate, SoftManager, and a fourth program — remain on the infected machine after the main stealer deletes itself, giving an infection a second life. One of the modules disables Windows Update and Microsoft Defender before running a cryptocurrency miner. That combination is particularly damaging because it removes the two mechanisms most likely to detect or remove the follow-on payload. Anyone investigating a suspected REVSTEALER infection should look beyond the original stealer binary and hunt for the lingering modules, since the machine may remain compromised and actively mined even after the initial malware file disappears.
