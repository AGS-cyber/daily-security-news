Actively exploited

SonicWall has warned SonicWall Warns of Two SMA1000 Zero-Days Exploited in Attacks that two SMA1000 zero-days are already being chained in attacks. CVE-2026-83548 is a pre-authentication issue in the Work Place interface, a flaw that gives an unauthenticated remote attacker an unintended alternate path to sensitive functionality and carries a critical CVSS score. The second, CVE-2026-83549, is an OS command injection in the appliance Management Console. Chained together, they give an unauthenticated attacker a route to arbitrary command execution on a VPN edge device. That is the kind of foothold attackers historically use to move into the rest of the network, and the fact that exploitation is already happening makes this more urgent than a typical advisory. Neither CVE appears in CISA’s known exploited vulnerabilities catalog, but in this case the exploit reports themselves are the signal.

JFrog Artifactory is next on the priority list Hackers exploit critical JFrog Artifactory flaw to forge admin tokens. CVE-2026-82329 is an authentication bypass that, under default configuration, lets an unauthenticated attacker with network access obtain administrative privileges. The public description maps directly to what attackers are doing: forging tokens that grant admin access. The vulnerability was disclosed only days before the first exploitation reports, and the CVSS score of 9.8 reflects how little an attacker needs to do. Organizations running Artifactory should treat unexpected admin token creation as a possible indicator of compromise, and should assume that any instance with prior exposure may already be in someone else’s hands.

The active exploitation theme also reaches AI infrastructure. Langflow Critical Langflow flaw exploited to steal OpenAI and AWS keys is being hit through CVE-2026-0768, an unauthenticated code injection flaw in the validate endpoint that allows remote code execution in the context of root. The observed attacks are not reconnaissance; they are stealing OpenAI and AWS keys. For any team using Langflow with connected cloud credentials, this is a direct financial risk as well as a data risk. A root-level compromise of an AI workflow engine means the secrets it can reach should be considered burned.

VoIP systems are a less glamorous but equally exposed target Attackers Exploit Critical Switchvox Flaw to Deploy Reverse Shells Without Credentials. Sangoma Switchvox SMB Edition is under active attack via CVE-2026-9586, a critical unauthenticated SQL injection in the /pa endpoint. The flaw lets an attacker send a single crafted request to the backend PostgreSQL database and move from SQL injection to remote code execution, with no valid credentials required. Attackers are using it to drop reverse shells on internet-exposed systems. Switchvox deployments should be treated as high-value targets; the product handles internal communications, and a compromised PBX can become a silent eavesdropping point or a launching pad for further intrusion.

Breaches

Supply-chain trust took another hit this week BGP Hijack Delivers Malicious Virtualizor Update That Establishes Persistent Root Access. A BGP hijack redirected update traffic for Softaculous, allowing attackers to deliver a malicious Virtualizor package to some installations. The update was accompanied by a valid TLS certificate, which means signature and certificate checks alone would not have saved a victim. The result was persistent root-level compromise of hypervisors, with one hosting provider reporting that five of the thirty-four hypervisors it checked had been rooted. When the hypervisor is compromised, every workload on it is suspect. This incident is a reminder that update integrity depends on the path as much as the certificate, and that routing-layer attacks can undermine software distribution channels even when the cryptography is sound.

The breach at the Philippines’ nuclear agency Old, Unpatched Flaws Give Attackers Access to Philippines Nuclear Agency is less exotic but just as instructive. Attackers gained initial access by exploiting old, unpatched ownCloud vulnerabilities, then stole reactor databases, personnel records, and credential stores. No sophisticated zero-day was required; commodity flaws were enough. The damage was done because the target failed to patch known issues in an internet-facing component. For defenders, this is a case study in why vulnerability management is still the foundation of security, no matter how much attention the newest edge cases get.

Industry

Law enforcement may have written a new playbook for dismantling P2P botnets Authorities Turn Sality's P2P Network Against Itself, Cutting Off New Malware Payloads. The Sality botnet, which survived for more than two decades, was effectively neutralized when authorities from the United States, Bulgaria, Hungary, and Romania, working with CrowdStrike and the Shadowserver Foundation, turned its own peer-to-peer network against it. Instead of merely taking down command infrastructure, the operation cut off the botnet’s ability to distribute new payloads. That is a meaningful operational result: existing infections may remain, but the ability to refresh them with new malware has been disrupted. For defenders, it also shows the value of private-public cooperation in attacking the structural properties of criminal infrastructure.

Vulnerabilities

Finally, researchers at Manifold Security have disclosed a class of flaws affecting multiple command-line AI coding agents, including Claude, Codex, and Cursor Malicious .git Configs Can Make Claude, Codex, Cursor, and Other AI Agents Run Attacker Code. Eight issues across seven tools let a malicious repository’s own Git configuration name a command that the agent executes on the developer’s machine. The command runs as the user and outside the agent’s sandbox, without an approval prompt. Four of the tools were still unpatched at publication. The exploitation requirement is minimal: a developer merely has to clone and work with an attacker-controlled repository, which is normal activity. This is a reminder that AI coding agents inherit the trust developers place in the repositories they open, and that sandboxing alone will not protect against repository-supplied configuration.
